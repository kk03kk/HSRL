## 本次完整回放发现的策略问题

此前只看抽样回合，称“未触发80动作强制结束”不准确。完整288局（3模型各96局）里发现3个第1回合事件：起点1局、5506零局、6039两局。序列均为买1次、打出40次、取消40次、最后结束1次，总计82动作，标记forced=true。

评测策略的80是触发结束保护的阈值，源码条件为动作计数>80且EndTurn合法；处于待选时不能直接结束，因此记录可能超过80。这是现有规则口径，5次换位约束仍全部满足。这里同时暴露了贪心策略的play/cancel无进展循环，不能把它说成正常有效经营；有保护收尾，非非法动作或引擎卡死。当前不修改运行配方，列入收尾后的有针对性修复。既有评测协议和原始数据不改写。
