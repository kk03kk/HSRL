## 最新研究结论

- 8个能力PPO固定终点共 **48,379,721** 采样决策，训练器核实全部进入优化流程；未确认自然棋力提升。
  已停止继续延长原窄过程BC/普通核心赋予课程配置，不能据此否定全部专家学习或课程方法。
- 金倍增四核心起点的growth教师有明确完整续局优势：49源/98配对，平均名次2.735→1.551，
  名次差−1.184，95%源聚类区间[-1.643,-0.714]。这属于显式赋予组件的条件能力，不是自然组建。
- 学习者已有条件成长收益：重放学生相对父模型共同T9–T12 log成长+0.282 [0.163,0.399]，
  45源/84配对；但名次+0.286 [-0.194,0.786]，未确认总体提高。没有把T12幸存者P50单独当棋力。
- 一轮学生状态聚合学会旧查询，恢复核心匹配85.98%，实际自身状态教师匹配69.37%；
  但相对同预算重放名次差+0.082、成长差−0.057，区间均跨零。不再追加聚合轮/PPO。
- 强制部署钩牙、阻止卖掉最后门控组件的单项因果对照均未确认名次收益；不永久部署这些手写规则。
- 仅清空教师cycled循环记忆后，名次变差+0.704 [0.327,1.102]；原生两段合法历史还证明
  相同现有观测可以对应不同教师选择。它证明教师标签的可表示性限制，不证明最优策略一定需要RNN。
- D-113旧开发固定底座残差有条件收益，随后65个新来源/各130续局验证已完成。
  有历史减父模型名次−0.1308 [-0.5385,0.2769]；共同成长+0.2630 [0.1367,0.3925]，62源/113对。
  冠军45→62/130，前四111→107/130，冻结效用差区间跨零。有历史与无历史差异仍不确定。
  条件成长泛化得到支持，整体棋力及历史单独贡献未确认；不晋升、不继续扩大这条PPO。
- 原生三连首买在growth后续下名次改善−1.1786，在parent下均值0；14来源交互区间仍跨零。
  支持研究后续兑现与前置投资的衔接，不是自然形成或普适购买标签。
- 已学循环的金起点常触100动作；有历史T12触顶43/90，末20步总攻血增量中位420，
  强制结束金币15/手牌4/场位6，无大量重复移动。应研究固定预算内收尾，不直接改评测上限。
