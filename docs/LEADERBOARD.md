## 1. 我们的简化规则

用户明确选择简化规则，不采用 FIDE 的 K 因子/评级周期/最低局数等完整流程。当前规则：

1. **只有一个榜**。新榜替代旧榜；旧榜文件归档，不删除原始证据。
2. **只保留强模型**。榜最多 8 个模型；弱模型由用户决定删除/归档，不再长期占榜。
3. **旧模型分数冻结**。已有模型保留上一版 4 模型 Elo 的分数，作为新模型的锚点。
4. **新模型用 gauntlet 直接算分**：
   - 与榜内每个模型各打 128 局（2 焦点模型 + 6 引擎 bot，8 座位轮转）；
   - 旧模型分数固定，新模型用 **fixed-opponent Bradley-Terry MLE** 拟合唯一分数；
   - 用 5,000 次 game-level bootstrap 给 95% CI；
   - 计分胜率 = (胜 + 0.5 平) / 总局数。
5. **排名按点估计 Elo 排序**；CI 同时报告，用于标注可信度。
6. **实机选择与 Elo 榜分开**：Elo 决定“值得上实机”，实机仍走 `live-v1` / 真机验收。

> 注意：gauntlet 不是完整 round-robin；旧模型之间的对局不重打，旧分数是冻结锚点。
> 这是用户选择的简化规则，不是 FIDE 官方评分。直接对当前第一的 128 局 CI 可能跨 0.5，
> 因此“榜第一”是点估计，不等于已证明的显著超越。

## 4. 新模型入榜流程

1. 模型审计：SHA、架构、卡表、词表、真实观测前向、引擎指纹。
2. Gauntlet：与当前榜每个模型各 128 局；0 illegal / 0 truncated / 0 engine_bad。
3. 算分：旧模型固定，新模型 fixed-opponent BT MLE + 5,000 bootstrap。
4. 入榜：按点估计排序；若分数高于当前第一，则成为第一；否则按分数插入。
5. 清理：只保留最多 8 个模型；弱模型由用户决定删除/归档。
6. 实机：入榜不等于实机通过；实机仍需单独验收。
