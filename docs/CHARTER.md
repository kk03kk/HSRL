# HSAI 项目宪章（目标 / 研发模式 / 迭代流程）

状态：**当前生效**（2026-11-14 建立，取代此前"Agent 自主规划多天"的工作方式）。
本文件回答四个问题：我们在做什么、谁做决定、一轮怎么走、什么叫"变强了"。

---

## 1. 项目目标（唯一口径）

训练一个能在《炉石传说：酒馆战棋》里**实战下棋**的 AI（Hearthstone Battlegrounds AI，简称 HSAI）。

判据不是"排位分数好看"，而是**中后期棋力**：模型在第 8 回合之后，能不能靠自己做对"升本 / 买随从 / 站位 / 转阵容"这些决定。

**唯一的两个过程指标**（用户 2026-11-14 定，其他指标一律降级为诊断用）：

| # | 指标 | 定义 | 口径 |
|---|---|---|---|
| **M1** | 逐回合**中位战力** | 每回合"战斗开始前"己方战团 Σ(攻+生命) 的**中位数** | 逐回合列出，从第 1 回合到最后；必须给样本量 n |
| **M2** | 逐回合**平均酒馆等级** | 同一时点的 tavern tier 均值 | 逐回合列出 |

**判定棋力用的是名次面板**（M1/M2 是"过程刻度"，名次是"结果刻度"，两者都要看，但不混谈）：
mean_rank / top4 率 / 冠军率 / 非法动作数。

**最终目标态**：成为当前最强版本（"冠军"），并且每一轮都能用同一套评测证明它没有退步。

## 2. 研发模式（2026-11-14 变更，重要）

### 2.1 谁做决定

| 角色 | 职责 |
|---|---|
| **用户** | 定总体方向；批准任何占用 GPU 的提交；批准训练配方/评测标准的**任何变更** |
| **Agent（我）** | 执行、分析、验证、写文档；发现问题时**提出建议**，由用户决定是否采纳 |

**硬规则：**
1. **不自主规划多天研发路线。** 不再有"Agent 自己决定接下来试什么、连跑两三天"的模式。
2. **任何消耗 GPU 的作业（训练、评测、建库）必须先得到用户明确同意**才提交。
3. **训练配方一旦冻结（见 §3），不每轮改动。** 只有发现**具体问题**（工程错误、指标异常、明确的机制缺陷）才提出修改建议，且由用户决定。
4. Agent 可以自主做的：读、分析、审计、改代码、写测试、跑测试（不占 GPU）、建目录、写文档、提交/取消**自己已获批**的作业、拉权重。

### 2.2 一轮迭代的固定流程

```
① 训练（用户批准的配方 + 当前战团库）
      ↓
② 评测新模型（同一协议，512 局，对手场 = 同一份校准库）
      ↓
③ 与当前冠军对比（M1 / M2 逐回合 + 名次面板）
      ↓
   ┌── 有进步 ──→ ④ 新模型成为新候选 → 基于它重新校准战团库 → 回到 ①
   │
   └── 没进步 ──→ ⑤ 归因分析（工程错误？对手场？奖励？容量？样本量？）
                      ↓
                  ⑥ 提出方法层面的修改建议 → 用户决定 → 回到 ①
```

**关键约定：**
- **每轮只改一个变量**（对手场、或奖励、或超参之一），否则无法归因。
- **新模型必须在同一协议下击败当前冠军**才算进步；不允许换协议混榜。
- **有进步就换库**：战团库永远对着"当前最强模型"重新校准（`tools/build_arena_library.py`），这是本项目已验证的唯一有效杠杆（D-052/D-054）。
- **工程错误严格停止**：非法动作、截断、引擎异常、注入失败、非有限损失、状态损坏 → 立即停并保留现场，不算作"棋力波动"。
- 正常棋力波动只记录，不自动止损。

## 4. 术语表（新人必读）

| 术语 | 含义 |
|---|---|
| **冠军（champion）** | 当前最强、且用统一协议验证过没退步的模型版本。目前 = `league-final-20261111-step014858` |
| **战团库（warband library）** | 从真人对局里收集的真实战团，按回合分桶；训练时注入给对手席位当对手 |
| **校准（calibration）** | 让"每回合对手强度"= 当前模型该回合中位战力 × 系数（前期 0.85 略弱，第 9 回合 1.00，后期 1.05–1.15 略强） |
| **快照库（snapshot library）** | 战团库转换成"回合末整席快照"格式（`snap_*.json.gz`），训练器按 `(turn, seat)` 注入 |
| **镜像注入（mirror injection）** | 训练时把快照库的对手战团放进非 learner 席位 —— 本项目唯一被验证有效的"难度杠杆" |
| **MIG 切片** | 本站 `h100-47` 是 3g.47gb 的 MIG 切片（46.4 GiB），不是整卡；见 `TRAINING_RECIPE.md` §6 |
| **论文** | AutoTavern（Build, Don't Play，[arXiv:2610.33845](https://arxiv.org/html/2610.33845v1)）—— 我们的引擎与训练配方的主要参照 |
