# 当前强化学习链路与本轮验收

2026-10-27。当前发布：entity-library-v2；启动步骤见NUS_ENTITY_LIBRARY_START.md。

1. **环境**：作者36.6.3基准＋已确认的先攻修正＋37.0/37.0.1公告定向修复，原生c5ae8b29643c63f7。随机十选五（不含纳迦），不强制五种族，不设Move专属上限。训练和评测使用每回合200次工程预算，模型已有已用/总预算输入。
2. **CPU准备数据**：保持原始随机大厅分布。按原生flow.rs列举2,072个合法种族/神明/悖论上下文，实际原生新建游戏扫描出各上下文的种子。训练、验证、测试使用互不重叠的种子区间，每个上下文至少一个完整机器人源大厅，即至少6,216个源大厅；每大厅提取8个席位的逐回合模板。坏源局不作为正常名次，缺失上下文从独立种子段补采，仍缺则阻止GPU作业。三份库的source_group交集必须为空。
3. **真人资料**：用户第一局1–12回合代理只放训练库，按匹配上下文混入。开战后攻击不重复加成。一个上下文中的权重约11%，全随机大厅下总体占比极小；当前库总体仍是机器人基础库，未声称现实强度已校准。验证／测试没有独立真人比赛，不能报告真人泛化成绩。
4. **输入与模型**：仅玩家可见观测、当前合法动作掩码、自身计数等扩展；隐藏手牌/未来库帧不送给策略。124卡槽归并到49实体token；静态卡牌属性＋离线TF-IDF/LSA128规则表示；384维、8层、8头、FF1536，无GRU，17,962,378参数。仍为245语义动作和合法掩码；需要选择/目标时继续逐步决策。本模型不是旧小GRU的直接扩容恢复，也不是作者私有模型的逐项复刻。
5. **GPU资源资格**：先对1796万模型做真实前向/反向/Adam更新的资源探针，报告显存峰值与耗时，丢弃探针权重并恢复随机状态。若CUDA OOM，只减小微批量、增大梯度累积，最多约2048个有效状态的累计规模保持，不缩小网络。最低32状态仍失败则明确失败，不偷偷改CPU训练或启动正式长训。
6. **BC初始化**：大架构全新初始化；32个并行普通经营大厅、每大厅1个学习席位，脚本教师采集，16波×4epoch，Adam学习率3e-4。通过独立教师动作一致率≥50%、足够样本、固定机器人greedy/sample均值名次≤6.5且无截断，才保存bc-ready并继续。BC门槛是基础行为检查，不是高手资格。未通过保留candidate与gate报告。
7. **库PPO资格训练**：学习者正常买卖/施法/站位，七个对手从相同上下文的训练库采样逐回合战团；对手不执行经营策略，也不使用当前模型自我博弈。模板为招募结算后、开战前；原生进行战斗、伤害、淘汰与配对，学习者自然出局结束大厅。库复制体免池份额，轨迹尾部保持末帧，是明确的代理假设。只记录真正applied的学习者动作，延期不推进记忆/决策计数；失败/截断不伪装为正常第八。
8. **优化与选优**：终局名次线性奖励(9−2rank)/7，gamma=1、GAE lambda=.995；PPO clip=.2，Adam6e-6，价值及辅助名次损失、熵系数.002，初期BC anchor KL；KL和梯度保护保留。资格预算50,000个新增有效PPO样本，重复epoch不充数。首选微批256状态×8累积，尾批按真实有效样本加权。独立验证库的sample成绩选best，同时报告机器人与greedy表现；每次完整更新后保存latest，支持信号中断保留上个完整checkpoint。
9. **保留测试与下一决策**：对BC/latest/best在源对局分离的测试库和固定机器人上各测greedy/sample；两种子×8大厅=每面板16个独立大厅，报告置信区间、失败/截断、显存和吞吐。只有status=completed才表示资格训练及考试完成。根据本轮实际学习增益与速度，再决定扩大训练；不自动宣称顶尖棋力或启动真实游戏。
