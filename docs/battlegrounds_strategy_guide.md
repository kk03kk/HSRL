# 酒馆战棋流派攻略

第 14 赛季，33 个公开流派，5 个 S、17 个 A、11 个 B。2026-11-21 逐项对照 [HSReplay 第 14 赛季攻略](https://hsreplay.net/zh-hans/battlegrounds/comps/)。网页最后更新为 2026-11-14 21:08（UTC+8）。[37.0.3](https://us.forums.blizzard.com/en/hearthstone/t/3703-hotfix-patch/168317) 于 11 月 17 日作为服务器热修上线，页面没有单独标明热修后的分层。强度分层引用网页，牌池与动作可行性按运行版本逐项判断。

热修影响三条常见成长线。邪能野猪人每施放 **4** 个法术才吞噬，鲜血勇士的战吼和亡语每次为宝石额外提供 **+1/+1**，尖利的鲨鱼升至 **5 本**。因此评估法术吞噬、宝石成长和野兽进击是否及时成型时，采用热修后的条件。流派排名是否随热修改变待确认。[暴雪 37.0.3 热修公告](https://us.forums.blizzard.com/en/hearthstone/t/3703-hotfix-patch/168317)

保留原有核心、附加卡和过渡速查，按正文核对形成条件，更新全部操作说明和来源链接。极紫外升腾者从 A 调至 B。旧版全文在 `records/archive/strategy-guide-20261121/battlegrounds_strategy_guide.md`，两端均可用 `git show 2bdb97e:docs/battlegrounds_strategy_guide.md` 查原稿。


## 策略 Bot V1.0

以下为旧项目 V1.0 教学记录。HSRL 使用 37.0.3 引擎，验证记录见[策略 Bot](STRATEGY.md)。保留此前八条专项逻辑，新增本攻略余下 25 条路线。选线使用实际在场、手牌与商店中的组件，并在已有引擎运行时提高转型门槛。开局英雄按 HSReplay 选择率，饰品按统计和指南结合评分。模拟器仍使用本项目的 37.0.2 运行规则，按默认十族池每局随机抽五族。

在项目根目录运行已构建的示例。最后一项写 `v1.0-only` 只运行 V1.0，写 `v1.0` 会在同一批种子和座位上加跑上一版八套路 Bot（带 HSReplay 英雄和饰品规则）。

```powershell
.\target\release\examples\strategy_experiment.exe 390000 1000 8 runs/strategy-v1-local v1.0
```

`v1-coverage.md` 统计 33 条路线的选过、启动和完整局数，`v1-showcase.md` 记录新增路线从实际对局抽取的战团，`v1-routes.csv` 可按种子核对新增路线的选线、首次出战和成型回合。各模式都由同一个示例驱动，每个测试席面对七个原版 Bot。

## 五族转型专项 V1.2

`strategy_v1_2` 在第 9 回合、五本及以上开始评估从永恒骑士、腐泥或手牌宝石转型。目标路线必须已有可用组件，当前金币能买下其余启动牌。低血量时只考虑能利用场上同族组件的转型。确认路线后先买组件和保住主力战力，再逐步替换弱牌。若转型组件尚未到位，就继续使用当前过渡阵容。

V1.2 新增的六本搜索要求手牌或场上已有六本目标的配合牌、上一场未掉血、血量加护甲至少 24，且升本后还够刷新和买一张随从。原有升本判断继续适用。

`pivot` 固定海盗、亡灵、机械、野猪人、畸变怪，用相同种子和座位比较 V1.0 与 V1.2。两组各自面对七个原版 Bot。`pivot-only` 在同样种族下只运行 V1.2。

```powershell
.\target\release\examples\strategy_experiment.exe 540000 1000 8 runs/strategy-pivot-local pivot
```

`pivot-report.md` 记录前期过渡、已上场的后期组合及其启动情况。`pivot-games.csv` 包含逐局的转型时间、场面估值和当轮胜负。

当前所有新实验默认每席每回合 100 次招募操作。达到上限后结算已打开的菜单并结束招募。此前生成的评测报告用当时各 Bot 自身的操作预算。

| 中期节奏 | 探险者的望远镜、魔术师的高帽可以补铺场。旅店老板的酒杯适合留五本找六本牌；转录打字机在四本拿通常更容易马上兑现。 |
| 有条件的成长 | 参训证书依赖泰蕾苟萨；精灵龙鳞在已有龙阵容和执念诗心龙时有更明确的收益。加重护手可以用达卡莱附魔师加快。 |
| 三连与过渡 | 大教堂模型可留给高价值法术，例如三连奖励。地精钱包、磨损的藏宝图、闪光水晶适合把资源延续到下一步运营。 |
