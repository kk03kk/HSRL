## 已落地的改动

- 样本采集的 GPU 批推理改为在同一流上提交主机到设备的数组复制，动作编号、log-prob 和价值一次回传。单批请求直接使用原来已打包完成的连续数组，省去一轮拼接复制。[采样批处理](../../hsbg/az/train/batch_eval.py) · [模型批推理](../../hsbg/az/train/ppo.py)
- 换位守卫批量清除已触顶的 Move 位，旧重复限制只扫描实际用过的槽位对。8,000 次差分调用覆盖 5 组旧／新守卫参数，掩码、强制结束标志、记账和异常行为一致。触顶路径本地微基准 11.27→4.21 微秒。该改动单独在 GPU 全链路几乎持平。 [换位守卫](../../hsbg/az/train/move_guard.py)
- 评测共用同一步已经解码的玩家状态，保留战前／结算前棋盘、金币账和机制记录。群友原版单步推理把合法性检查、argmax 与价值合并回读。 [评测入口](../../hsbg/az/train/evaluate.py) · [群友推理入口](../../workflows/peer_ppo_panel.py)
