# 活化艾泽里特课堂与夜间 PPO 的交接

本轮从真人场第 3265 版训练一份标准实体策略。野猪人投资版只在野猪人课堂提供动作分布，原版在自然状态提供参照。三个来源在一次训练中更新同一个策略。冻结的野猪人学生仍可单独用来复习该技能。

## 如何衔接一晚正式训练

1. 候选达到课堂门槛后，逐步移除预置，在相同自然中局看它是否愿意投入、有无收益、何时放弃。用新的自然整局种子和留出真人库对照第 3265 版，检查效用、前二、到达率及龙械回归。依机会、投入与中途退出分组，和普通整局一起报告。只有课堂达标时，保存技能候选，夜间算力可先用于入口课程和配对续局。
2. 通过自然门槛后，生成独立模型档案和**新一轮配方**。首段明确指向联合学生及其 SHA、manifest SHA，使用新种子和新运行目录。冻结同一份学生作为 PPO 初始参照，重建 Adam、调度器、随机数与计数。上一轮配方内的初始模型和系列目录属于旧实验。启动前用训练入口验证载入的权重、协议、真实库和前向结果，短程检查采样、更新及保存恢复，同时跟踪两种技能是否快速衰退。
3. 一份模型、一条种子轨迹、两个 H100-47 切片。可从已验证的真人场 PPO 配置开始，512 局/批、8 个采样进程、1 epoch、minibatch 1024、累积 8、学习率 6e−6，保留原终局效用与真实战团。用联合学生自己新采样的动作和旧 log probability 计算 PPO。如需复习教师状态，单列小权重监督损失、单独采样并核对保留效果。调整时以短程验证为准。
4. 若获准连续训练一晚，可沿用四段、每段至多三小时的服务器接力。段二起只从前段成功封存的同代 `model.pt` 与 `trainer.pt` 完整恢复；前段失败不启动后段。首段、半程和终点保留模型，报告学习曲线、两项技能与自然整局效果。新一轮首次正式开训仍由用户决定。
