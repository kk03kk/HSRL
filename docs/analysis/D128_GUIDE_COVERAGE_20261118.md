# D-128 与现役攻略 33 个流派的对照

每格顺序均为父模型 / A / B，每组 512 局。流派可重叠。前两列独立统计，打出包括磁力部署，来源可为购买、发现、奖励等。可买指曾出现在合法购买掩码中。
