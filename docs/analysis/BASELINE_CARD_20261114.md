# Champion 基线卡（2026-11-14，固定口径）

用途：**明天/后续每次验收都拿这张卡对照**，不许改口径。数据来自
`artifacts/runs/gap-five-20261113/panel.json`（本轮五个臂同批跑的那一份），
`base` = `league-final-14858`（36h champion）。

## 0. 读这张卡前必须知道的两件事（2026-11-14 01:05 补）

1. **参照系是"赢家样本"，不是随机玩家**：6k 库 603 局里 99.8% 的 `placement` 是前四、中位名次 = 1
   （见 `RUNS §5.63`）。所以下文"真人 P50 板面"是**吃鸡级**玩家的同回合水平；
   拿我们"所有存活局的中位"去比它，会系统性低估我们。
2. **对手场同样是赢家级**：每局 7 个座位都从该库注入。champion 的 `mean_rank 5.4375`
   是在"被 7 个赢家级战团围殴"下取得的；8 人局里若 7 个对手都是前四水平，
   中位玩家的期望名次本就在 4.5–5 附近 ⇒ **5.44 ≈ 落后赢家场 1 个名次**，不是"很菜"。

⇒ 验收硬门槛仍是**同对手场、同种子的 rank 配对 CI 上界 < 5.4375**（这是唯一可比的量），
但**不要**再把"T12 板面 0.275×"当成"我们只有赢家 1/4 所以一无是处"来解读；
它是"距离吃鸡级板面还有 3.6 倍"的**长期**目标。
