# 中后期入场课程的真正病灶：升本节奏（tier tempo）被带慢一整级

状态：**诊断完成，修复实验运行中（G2/G3，2026-11-12 22:52 起）**
入口：`tools/inspect_gap_panel.py`、`artifacts/runs/gap-e3c-20261112/panel.json`、
`artifacts/runs/human-gap-f1-20261112/panel.json`、`config/league-entry-g2.json`、
`config/league-entry-g3.json`

## 0. 一句话结论

中后期入场课程（E3，entry 回合 9–11）让模型在**入场局**里的板面比同回合真人曲线提高
10–24%，但把整局面板弄差了；逐回合拆开看，**前 7 回合几乎没变，崩的是 T8–T12 的升本
节奏**：learner 在 T10 的平均酒馆等级只有 **4.62**，champion 是 5.25，真人是 5.52 ——
慢了整整一级。板面强度在 T12 之后随之下塌（T14 −30%）。

因此，之前"把入场回合提前（F1/F2）"的方向是**错的**：F1（入场 T6–8）把病做得更重
（T10 之后停在 tier 4.5–4.7，mean_rank 1.417）。真正要修的是升本节奏，不是入场时机。

## 3. 机制解释（与代码一致）

`hsbg/az/train/parallel_collect.py` 的入场课程在 `T0` 之前把 learner 交给 bot 打，
**不产生任何 learner record**（`_entry_pending`）。于是：

- 训练里 learner 永远从"已经被塞进一个 tier 5–6 真人战团"的状态开始，
  "T8 之前升到 5 级"这个决策从未进入梯度；
- PPO 更新的却是共享网络，T9+ 的策略改动会**无监督地漂移**早期行为；
- `board_target` 奖励按回合比较 learner 与专家板面，它奖励"这一回合板面大"，
  而升本当期会掉板面 —— 于是"别升本、买属性"成了局部最优。

这与 champion 自身的老毛病（`tier_target` 模块注释里记的"turn 9 起恒为 4"）同源，
只是被入场课程放大了。

## 4. 修复：直接把升本节奏写进 reward（tier-target）

`hsbg/az/train/tier_target.py` 早就实现了"按回合目标等级直接改 reward"：
每个新回合起点读一次 tier，未达目标扣 `coef*penalty`（0.02），首次达标一次性加
`coef*bonus`（0.15），默认目标表 `7:4,9:5,12:6`（= 真人曲线取整）。**此前从未开启过**。

本轮做了两件工程事：

1. `hsbg/az/train/personal.py` 的 `OPTIONS` 增加 `tier-target-coef / tier-penalty /
   tier-bonus / tier-target-table`（否则 config JSON 会被"未知配置项"拒掉）；
2. `hsbg/az/train/runlog.py` 的 `INJECTION_KEYS` 增加 13 个 `tier_*` 键 —— 这是
   `board_target` 踩过的坑：配了但没进 history，就会静默跑完一整段还看不出来。
   `tools/analyze_entry_run.py` 相应增加 `t_hit% / t_rw / bt_rw` 三列。

实测（首轮即确认生效）：G2 `tier_checks` 有值、`tier_hit_rate ≈ 0.60–0.68`、
`tier_target_reward_sum ≈ +83..+98/轮`（≈0.17/局，对比名次奖励约 1/局，量级合理）。

## 5. 两个修复配方

| 配方 | 入场 | entry-p | board-target | tier-target | 目的 |
|---|---|---:|---:|---|---|
| **G2** | T9–11 p75 | 0.5 | 0.30 | 1.0 | 混合课程 + 升本节奏（一半整局、一半入场） |
| **G3** | T9–11 p75 | 1.0 | 0.30 | 1.0 | 只加 tier-target（与 E4 只差这一项） |

G3 是 E4 的单变量对照（E4 = 同配方无 tier-target），G2 检验"混合课程是否还需要"。

## 6. 验收口径（沿用四件套，逐回合判读）

1. **逐回合 tier**：T8 ≥ 4.5、T10 ≥ 5.2、T12 ≥ 5.3（对齐 champion，而不是只追真人）；
2. **逐回合板面比值**：T12 从 0.24 起、T14 从 0.11 起不能退；
3. **结局**：`mean_rank` ≤ 1.18、`survive>t14` ≥ 0.79；
4. **入场局内在指标**（`tools/analyze_entry_run.py`）：固定回合绝对板面不能因为我
   改了 reward 就变差；`tier_hit_rate` 必须单调上升。
