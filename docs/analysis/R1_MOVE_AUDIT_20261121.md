# R1 实机反复换位审计

## 结论

主要问题是策略主动选择了许多会撤销自身效果的换位，现有守卫只约束动作编号，无法识别棋盘已经回到原处。训练收益集中在终局，旧环境里反复换位既不花金币，也没有显式招募时间成本。在这一条件下，保护原策略动作分布的 KL 锚定、通过逐步轨迹学习的长程信用分配以及相邻换位的重复编码，都可能让原有偏好保留。现有证据能区分决策和执行，尚不能量化 PPO、KL、动作编码和观测差异各自的因果份额。

长期应把站位建模成**是否改变和改变后的阵型**。保留能改变招募效果的中途换位，控制纯换位序列中重复出现的阵型。战斗前让模型在原位和候选阵型之间学习条件选择，以真实时间或可靠校准的预算计算代价。

## 实机决策到回执

使用独立 Windows 实机分支的七个记录段，按真实对局 ID 合并重启后的记录。共五个对局 ID，其中一局只有英雄选择，其余四局有 33 个观察到的招募回合。中断后缺帧的回合保留，分母限于观察到的区间。决策以原始 `decision_id` 为键，鼠标输入要求原生轨迹有成功的左键按下，成功要求同 ID 的 applied 回执。循环统计另外核对了实体编号的顺序和插入动作定义。

循环计算只连接相同回合内连续确认的换位。接续处要求实体顺序相接、记录中的场上属性及非站位字段相同；所有已发出但未确认的操作和其他动作均截断序列。25 次换位期间还有被记录的其他状态变化，单列并跳过。178 次是该识别条件下可从执行序列擦去的步数。不能用这个数字推断中途耗时为零或保证全部未观测字段相同。

`219` 对应从索引 3 插到索引 2。移动后原索引 2 的随从现在处于索引 3，再执行 `219` 就回到原顺序。守卫屏蔽的是另一个编号 `213`。同一个编号在两步里绑定到不同实体，逐步确认说明这两次是独立且实际生效的模型决策。七只随从都有合法位置时共有 42 个非对角换位动作编号，但只有 36 个不同的一步后继阵型。两只随从时，两个编号对应同一种交换。按编号的重复上限也无法表达三步以上的闭环，或输入实体变化后的有效重复。

冻结权重在 631 个保存了可核对向量及合法掩码的招募决策上重算，按输入和合法掩码 SHA 对齐，首选动作 631/631 一致。245 个换位决策各有合法的非换位动作和 EndTurn，其中 211 个当时有金币。仅在模型已经首选换位的样本中，最佳 Move 相对最佳非 Move 的中位 logit 差为 2.62，Move 家族在合法动作 softmax 上的中位概率质量为 97.5%。这是条件性的政策分数，不是胜率或真实行动收益。按实机已发生的历史在第 3 次确认后遮掉 Move，原轨迹的 168 个换位决策会改选。最常见改选为打牌 49、激活 47、刷新 15、买牌 14 和暗黑之赐 14，只有 8 次改选直接结束。这是同状态重评分，走上替代行动后，新轨迹的后续局面另计。

对 R1 而言，实机 EndTurn 是停止提出操作、等待客户端自行推进，训练 EndTurn 则立即让该玩家结束招募。上表的“随后有招募动作”按回执判定。“最后的换位”按最后一段动作判定，不能直接换算成距离真实战斗还有多少秒。

## 训练契约与因果边界

| 路径 | 回合总预算 | 换位上限 / 反向规则 | 实测或依据 |
| --- | ---: | --- | --- |
| 实机 R1 的原训练与固定场评测 | 300 自主步骤 | 10，屏蔽紧接的反向编号，同编号次数不限 | NUS 1170497 的 `fit/run.env` 与 1170498 的固定评测协议 |
| 当前本地 R1 控制器 | 300 个确认计数 | 10，反向规则相同，同编号次数不限 | `Controller._guarded_bindings`，只对普通招募动作有效 |
| 现有 NUS Player150 第五轮 | 150 个引擎自主步骤 | 3，屏蔽紧接的反向编号，同编号次数不限 | NUS 1173164 的 `train/fit/run.env` |

实机 R1 与其原训练在换位上限和编号过滤上相同。训练记采样后已执行的引擎动作，实机以确认后的动作计数，因未知、失败和挂起结算而可能发生差异。实机对这款权重关闭同一换位的短期手势去重，确保同编号在新实体或新局面上仍可合法执行。Player150 是另一条从 R1 迁移后的路线，追加了剩余步数特征，实机没有加载其权重或采用三次上限。旧通用的两次守卫及另一个客户端模型的五次守卫也不适用此次 R1。

祖先公开策略在 D-154 的 1,024 局中，12,947 个有战前盘面的回合里 10,808 个用满十次换位（83.48%）。R1 首个采样批 25,996 / 113,412 次为换位（22.92%），最后第 646 批是 26,612 / 110,395（24.11%）。Player150 第五轮读取时的第 2884 批是 8,302 / 93,720（8.86%）。训练批比例受上限、模型、数据和阶段共同影响。识别新模型学到了多少，需要同协议对照。训练日志的 blocked cap 按移除的动作位计数。[D-154](PEER_STANDARD_BASELINE_20261119.md)

R1 固定场对七个同回合战团快照，使用纯终局名次效用，`gamma=1`、`lambda=0.995`、每步惩罚默认 0、搜索关闭。模型有专用 `h_move` 槽位头，在已学好的编码器上输出 49 个位置对评分。PPO 可更新此头，单步学习依赖从后续结果估计的优势。闭环里的多步动作主要共享后续结果，旧版也不提供可核实的剩余招募秒数或此前访问过的站位。即使发现原位与往返后的结果等价，终局奖励也没有自然理由让它偏好少走两步。实机拖动和确认会争用买牌、刷新等任务的时间。Move 分数显示策略偏好，单次位次的收益需靠配对试验判断。Player150 冻结配方见主工作树 `docs/analysis/PLAYER150_FIVE_20261120.md`。[R1 训练配方](PEER_GPU_ROUNDS_20261120.md)

## 配对模拟诊断

使用 Windows 37.0.3 兼容引擎，64 个事先固定的独立种子（573521000–573521063）。脚本 bot 自然经营，在 T5、T8、T11、T14 各选择 16 个种子的指定座位。固定所有其他席位的招募结果，在该席准备结束招募时克隆当前状态和 RNG。13 个指定座位提前淘汰，余下 51 个按原位直接结束、同编号相邻换位两次再结束、单独执行 R1 评分最高的合法换位再结束，分别推进同一轮。选单次换位时只读公开观测编码，不用战斗结果或隐藏对手信息选择。

- 两次交换在 51/51 样本恢复了原站位及相同的战斗结果。45 个样本战后完整状态相同，6 个样本的淘汰或终局座位只保留了多计的两步，其他字段相等。这个检验没有消耗真实时间。
- 只执行 R1 最高分的换位再结束，51 个样本里 22 个改变了当轮带符号伤害，11 个改善、11 个恶化。对实际全动作首选也为 Move 的 38 个样本，8 个改善、10 个恶化，其余 20 个相同。每个局面只有一个共同随机流，且是 bot 经营出的阵型。这证明摆法可显著改变战斗结果，不能用来判断 R1 的整局棋力或确定哪种阵型长期更好。
- D-183/D-184 使用原始策略、真人快照和 256 个配对新种子，将上限从 10 改到 8，省 5.18% 总决策。名次改善区间为 [−0.125, +0.234]，下界未过事先设置的 −0.10。缩上限是可检验的基线，现有证据不足以把它当作长期方案。[历史动作预算对照](PEER_ACTION_BUDGET_20261120.md)

## 长期路线与验收

1. 先对齐同一权重的训练、评测与执行约束，以后继阵型去掉相邻动作别名。逐步迁移时保留或显式重估旧动作概率质量，避免把掩码改变当作策略改进。用当前连续换位片段中的实体阵型和可见状态识别回到旧局面，阵容或其他有效状态改变后重新比较。这样避免走回已经见过的阵型，同时保留合法的多步重排。引擎能判断的严格等价和人为预算约束应单独报告。[动作掩码研究](https://arxiv.org/abs/2006.14171)
2. 把“原位进入战斗”和“采用一个新阵型再进入战斗”做成模型可以选择的动作。新阵型可通过逐个选择实体或插入位置生成；执行端再分解成少量可核对的拖动。候选评估比较同一阵容、不同排列的战斗或结束回合效果，使用多个共用随机流与可见信息能支持的对手分布，并保留通用中途 Move。相邻战吼可在出牌前受站位影响，左右边缘也能决定回合结束增益。战斗攻击顺序从左往右，仅看总身材衡量不出这些收益。[暴雪规则说明](https://hearthstone.blizzard.com/en-us/news/23156373/introducing-hearthstone-battlegrounds) · [相邻战吼](../../engine/crates/hsbg-engine/src/content/putricide.rs) · [边缘回合末增益](../../engine/crates/hsbg-engine/src/content/heroes_eco.rs) · [层次化动作研究](https://all.cs.umass.edu/pubs/1999/sutton_ps_AI99.pdf)
3. 优先把可观察的时间和动作实际耗时放进训练评测。比较原策略、匹配的硬上限、消除阵型循环，以及加入保留原位选项四种方案。单纯每换一次扣固定分会改变目标，可能把愿意花时间争取优势的有效换位一起压掉。若做奖励塑形，保留终局任务，并验证回报和棋力。周期中按阵型价值差构造的势函数在理论条件下会让往返净奖励为零，但仍需真实动作预算才能表达耗时。[奖励塑形的适用条件](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa09/readings/NgHaradaRussell-shaping-ICML1999.pdf)

后续隔离试验建议以相同种子、权重来源、训练剂量及对手面板比较，报告每回合循环次数、确认和耗时、结束时尚有合法用途的未用金币、名次及配对区间、前四/冠军和后期存活。战斗顺序另看配对伤害与胜平负，不能只用战团攻血。保留一组必须早调整位置的局面作正对照。是否允许晋级应在跑分前约定名次与强度的容许损失，使用独立模拟种子和实机回放分开判断。该方案尚无训练后整局证据。
