# 综合结论：HSAI 中后期能力差距的成因与已被验证的干预（截至 2026-11-13 09:30）

本文只写**有实测证据**的结论，每条都附证据位置。细节见各专题文档。

## 0. 一句话

模型的中后期问题**不是"不会铺满战团"，也不是"不知道要升本"**，而是三件事叠加：
**（a）**从不在核心卡上做乘法（缺 S 级引擎）→ 每格强度只有真人的 1/4~1/14；
**（b）**为了完成（a）需要 5–6 级核心卡，而它的**升本节奏与金币**不够；
**（c）**它打的是名次已经饱和的对手场（`mean_rank 1.177`），所以名次奖励**不提供改进压力**。

## 3. 已被**验证有效**的三个干预

### 3.1 对手库多样性（最大的单点收益）
把真人战团库从 8k（~60 局 / 1,168 行）换成 6k（~995 局 / **12,689 行**，强度只低 12–18%）：
`mean_rank` 1.333→**1.177（与 champion 相同）**、T10 +14%、T16 +15%。
证据：`gap-c1d1-20261113`（D1）。**56–60 局会过拟合，这是训练场的规模问题。**

### 3.2 阵容覆盖奖励（唯一把目标指标大幅推动的奖励）
`comp-target` 要求**同一流派 ≥2 张核心卡**才付分：
`≥1 S` 0.292→**0.500**（4 SE）、`≥2 core` 首次超 champion；
逐回合完成度**单调上升**（0.121→0.256），"完成度 ≥0.5 的局"在 T14 从 1.3%→**21.9%（17 倍）**；
**T5 核心卡获取率 22%→35%、T6 11%→18%**，且从"只会拼满永恒骑士（B）"变成
"能拼满鱼人/野兽等多个流派"。证据：`gap-h2-20261113` + §5.10/§5.11。
代价：板面 −12%（尚未解决，`H3` 在测）。

### 3.3 带板面门控的升本奖励（能把 tier 拉上去而不掉名次）
`tier-target` + 门控（"板面 ≥ 0.9×champion 同回合曲线才计分"）+ 6k 对手库：
T12 tier **5.55**（champion 5.36 / 真人 5.78），`mean_rank` 配对 CI 跨 0（不算更差）。
门控挡掉 60–75% 的检查，所以它是**稀疏但安全**的信号。证据：`gap-b2-20261113` 的 g6c/g7。
注意：同样的门控放在 8k 对手库上**无效**（tier 4.80）——**对手多样性是前提**。

## 4. 当前主线与未解问题

**主线**：`H2` 配方（6k 对手库 + `comp-target 1.0`、`min_hits 2`、`anchor-beta 0.1`），
正在长训接力（`entry-h2-20261113`）。并行 `H3`（+板面奖励）、`H4`（+严门控升本）。

**未解问题按重要性**：
1. **板面与覆盖的权衡**：覆盖上来后板面 −12%。`H3` 用 `board-target 0.30` 补，
   但 `board-target` 的口径是"Σ 总量"，而差距在"每格强度"，可能仍需改口径。
2. **5–6 级核心卡缺口 65–82%**：这是金币/升本问题，`H4` 用严门控升本去补。
3. **名次信号饱和**：champion 对 7 个引擎 bot 已 `mean_rank 1.177`。要真正"显著超过"，
   最终需要一个更强的评测对手场（例如把评测对手换成 p75 真人战团），否则
   名次类指标无法区分优劣。
4. **训练规模**：champion 来自 36 h / 5,316 轮，而所有 fork 都是 2 h / 100–200 轮。
   配方筛完之后必须给足算力，否则"显著超过"不可能达成。
