# 150 步环境与五轮训练

## 起点与规则

采用群友路线 R1 的第 647 次更新。R2 与 R1 在旧规则下各打了两组 256 对，有一组是独立真人战团。两组的平均名次差置信区间均跨零，T9→T12 的共同存活成长差也均跨零。新系列从 R1 权重分叉，首次建立新的 Adam、调度器与 R1 参考策略。第二至第五轮沿用前一轮末代的完整 Trainer。

模拟器以卡表 37.0.2.256589 为基础，服务端规则为 37.0.3，新引擎指纹为 `8bd1f4785018c474`。每回合每个招募席位最多有 150 个自主动作，观测包含剩余比例。手牌随从入场与选择落点合计一步。移动已在场的随从每回合最多三次，禁止紧接着反向移回。冻结与解冻共用两次额度。换位和冻结在招募期间都可以使用。步数耗尽时环境收尾，若发现窗口仍开着则由引擎按该局 RNG 在合法选项中选择。实机其他类型窗口在超时后的行为仍待确认。

模型输入含 4,967 个浮点数、124 个卡牌槽，输出为 245 个原生动作。保留原模型输入前缀，为自己的卡面、附件、显示数字、剩余步数、宝石与其他成长数值追加输入投影。卡文按卡位编码为数字与散列词特征，多个附件共用所在槽，原文保存在引擎接口。对手信息限于当前将遇到的对象及以前与之交手的战团、等级与回合。1172900 用反例检查了罗杰斯剩余金币、宝石质量和当前其他席位的私有区。实机读取、脚本耗时和所有单卡交互尚未逐张对照。

## 冻结的训练与评测

普通 GPU 分区每轮申请 3 小时，两片 H100 47 GB MIG，32 个 CPU，96 GB 内存。计划训练 175 分钟，距调度期限预留 240 秒。使用 1 个学习席与 7 个严格回合末战团席，随机抽样，超出库覆盖时使用项目的末次观测策略。自然五种族，无种族排除。256 局每批、8 个采集进程、PPO 每批 1 epoch、微批 1,024、梯度累积 8、clip 0.2、目标 KL 0.025、熵系数 0.001、初始学习率 1.25×10⁻⁵。前 100 次更新的参考策略系数 0.06，随后 0.04。名次效用从第一到第八依次为 1.00、0.35、−1.00、−1.15、−1.30、−1.45、−1.60、−1.75。搜索、强制升本、教师与额外身材奖励均关闭。

每五批保存恢复点，每轮单独封存末代模型和 Trainer。每轮末代与同一新起点使用留出场相同的 256 个配对种子。查看平均名次、第一与前四的配对差及区间，同时查看逐回合总攻血中位数和存活样本数、T12 到达率、共同存活样本的 T9→T12 对数成长。第五轮额外在真人战团场比较 256 对。固定场的变化可以比较五轮趋势。对真人实时对局的迁移表现待实机验证。
