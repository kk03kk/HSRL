## 开训门槛与调度

- 动作效率。D-154 共 458,014 次决策，其中 108,105 次换位，占 23.6%。CPU 作业 1168041 从四个分片固定取前八局，合计 32 局、14,787 个动作。3,400 次换位中的 1,416 次（41.6%）位于连续换位后恢复原站位的片段，占抽样全部动作的 9.6%。该比例只描述这 32 局的贪心基线，PPO 随机采样时的比例待测。D-152 旧规则下采样每批中位 14.53 秒，更新中位 3.84 秒，两者流水执行。新规则下优先用短训实测每秒完整局、换位率和采样/更新耗时，暂不调整动作标准或进程数量。数据位于 `artifacts/runs/nus-peer-overnight-audit-20261119-1/move-sample.json`。
- 训练得分待验证。D-152 的 555 万决策短训，384 局初筛正向，独立 512 对终局效用差为 -0.042，联合区间跨零。D-153 更准确地预测了名次，但对投资与即战力的选择收益没有确认改善。D-154 只验证新动作标准下的冻结策略推理。两批已更新的 1167942 使用旧契约，且已取消。
- 四段接力待接线。当前新标准的 `peer_open_ppo.py` 只起一段，默认终点评的是另 512 个种子。旧 `peer_ppo_continue.py` 写死旧动作协议和旧锚定。需将训练、接力和终点配置冻结为同一份计划，并在评测入口核对原版与 D-152 包装起点在新场的贪心等价。保护既有权重及取消作业的证据。
- 推荐只做一轮总计 60 批的试训，包括首段 8 批保存及第二段完整恢复至第 60 批。两段使用新标准、2 张 H100-47 MIG，一张采样、一张学习。检查双 GPU、实际采样与更新、非法动作与注入门、最终 SHA、存储代际、连续种子及 Scheduler/Adam/RNG/anchor 恢复。已有 D-152 的 CPU 恢复证据，新的 CUDA 接力待验证。预取流水线跨进程重建时，下一批可由当前版本重新采集，不能保证与单进程连续运行逐位相同。
- 候选与群友原版在新 512 局自然种子配对。扩训门槛为配对终局效用 95% 区间下界大于 0，双方到达 T12 的总攻血对数差下界至少 -0.12，并检查前二、T12 后成长和低血量组。未达到门槛时停在短训。正式末端仅在固定 1,024 局上报告一次。
- 若门槛通过并批准，短训终点作为第 1 段输入，后续四段每段最多 3 小时，均通过 `afterok` 串联。一次性提交服务器端；一个实验种子与一个全局训练批次计数器。每段保留约 2.5 分钟硬时限余量并校验完整 generation，失败时取消下游。昨晚四段 GPU 时长合计 11:51:05，段间等候 40 秒，但未来启动时间仍以 Slurm 调度为准。
