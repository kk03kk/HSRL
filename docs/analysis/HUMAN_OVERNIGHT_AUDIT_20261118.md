```bash
set -euo pipefail
dep=()
for segment in 1 2 3 4; do
  id=$(sbatch --parsable --time-min=00:15:00 --deadline=2026-11-19T10:00:00 \
    --kill-on-invalid-dep=yes "${dep[@]}" deploy/slurm/human_turn_ppo.sbatch "$segment")
  id=${id%%;*}
  echo "segment $segment job $id"
  dep=("--dependency=afterok:$id")
done
```

每段按实际获配结束时间与新加坡 10:00 二者中较早者控制训练，预留 90 秒关闭与保存，训练循环另在不足一批的余量时收尾。若短段估计 00:20 开始，距截止尚有约 9 小时 40 分，需要扣减段间排队和启停。长段按 08:33 估计最多尚余 1 小时 27 分；固定时长还可能因 deadline 无法满足而不获准开工。单个长作业的优势是只排队、初始化一次，若批准时队列发生明显倒转，重新比较两类请求。届时选用最后封存的终点，保留其绝对路径和 SHA 后评测。完成时间取决于独立的评测排队。
