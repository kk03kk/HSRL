## 4.5 读数噪声：`mean_rank` 的差别要先过 1 个标准误

96 局、8 人局，`mean_rank` 的单局方差约 1.5（绝大多数局第 1、少数第 6–8），
所以 **SE ≈ 1.5/√96 ≈ 0.15**。这意味着：

| 对比（96 局） | Δmean_rank | 能不能当结论 |
|---|---:|---|
| base 1.177 vs **G2 1.458 / G4 1.833 / H1 1.542** | +0.28 ~ +0.66 | **能**（≥2 SE） |
| base 1.177 vs B3 1.333 / C1 1.323 | +0.15 | **不能**（≈1 SE） |
| base 1.177 vs D1 1.177 | 0.00 | — |

反例警告：B3 与 D1 只差**训练对手库**（8k vs 6k 库），评估板面几乎相同
（T12 0.233 vs 0.243），但 `mean_rank` 差 0.156 —— 这个差正好在 1 SE 上，
**不能据此说"6k 库让名次更好"**，只能说"没有变差"。真正稳的是板面与覆盖这类
连续量（跨面板重现性 ±3%）。

落地要求：给 `workflows/eval_human_gap.py` 增加**逐局名次输出**
（现在只有 `mean_rank` 聚合值），才能算 bootstrap CI 并做配对检验。
在那之前：**名次类改动一律要 ≥2 SE 才算证据**，或者加局数到 256。
