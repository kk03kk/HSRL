## 1. 根因（已由截图与日志确证）

`artifacts/runs/live-e-20261111-108/match-0007/startup/blocked-last.jpg` 显示的是客户端的
**「重新连接 / 当前处于离线状态 / 游戏连接中断」**对话框，标题与按钮同名。
`lobby.py:111` 把 `重新连接` 归入“需要人工登录”，**拒绝点击**；唯一逃逸是
`dismiss_pending` 状态内 6 s 窗口，而重开一批后状态不是它 → 立刻 `Blocked` →
`queue-report.json` 记录 `elapsed 8.8 s, actions 0, inputs_sent 0` → 每批 7 次空转 → 停批。
9 批 ≈ 5 小时，0 局。
