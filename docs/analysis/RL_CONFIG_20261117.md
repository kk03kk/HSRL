# HSAI 强化学习系统 · 各模块配置总览

状态：**as of 2026-11-17 12:40**（逐项从代码与 `deploy/slurm/stage_arena.sbatch` 实取，
不抄文档）。本文回答一个问题：**这套 RL 系统由哪些模块组成、每个模块现在实际是什么配置**。

## 怎么读这份报告（三种口径必须分清）

| 口径 | 含义 | 例子 |
|---|---|---|
| **代码默认** | 函数的参数默认值（`PPOConfig()`、`EvalConfig()`、`build_entity_net()`） | `lr=3e-4`、`minibatch=64`、`epochs=2` |
| **生效值** | `stage_arena.sbatch` 实际传的值（**训练的唯一真值**） | `lr=6e-06`、`minibatch=1024`、`epochs=1` |
| **本轮实测** | 从 `history.jsonl` / `panel.json` 读回来的实际表现 | `1.03e5 决策/轮`、`ent 0.85`、`注入率 99.98%` |

**凡是"生效值"与"代码默认"不同的地方，代码默认值不参与训练**。本文每节都标明用的是哪种口径。
参数真值的唯一来源：`deploy/slurm/stage_arena.sbatch` + `docs/DECISIONS.md` 最新条 `D-###`。

## 1. 数据流总览

```
                      ┌──────────────────────── 8 个采集进程（进程级 actor pool）────────────────────────┐
 快照库                 │  引擎 hsbg_engine 37.0.2.256589（Rust）                                        │
 arena-cal-v14-snap ──►│   · 8 席：seat0 = 学习席（策略采样），seat1..7 = 每回合开始注入"整席位快照"→ended_turn  │
 (16,658 帧)           │   · 观测 3227 floats + 124 cards；合法掩码 u8[245]                             │
                      │   · 动作契约：max 80 / move-guard(5,2) / forbid-cancel / freeze-cap 2 / 禁黑名单饰品 │
                      │   · 每步落 record：features/cards/mask/action/logprob/value/forced/teacher_action  │
                      └───────────────────────────────┬────────────────────────────────────────────────┘
                                                      │ shm 环形 slot（--ipc-mode shm）
                                    ┌─────────────────▼─────────────────┐
                                    │ 父进程：batch 组装 + GAE + PPO 更新 │
                                    │  · 有效批 1024×8 = 8192，epochs=1   │
                                    │  · 奖励 = 终局名次效用（只奖前二）    │
                                    │  · 教师 CE（升本）+ KL anchor       │
                                    └─────────────────┬─────────────────┘
                                                      │ 版本化权重 w_%06d.pt（pipeline lag≤1）
                      ┌───────────────────────────────▼────────────────────────────────────────────────┐
                      │ 产物：model.pt / trainer.pt / history.jsonl / snapshots/step_*/（每 5 轮，留 3 份）  │
                      └───────────────────────────────┬────────────────────────────────────────────────┘
                                                      ▼
       评测：8 分片 × 128 局 = 1024 局（seed 930000..，同契约、同 held-out 场）
             → 分片 panel.json → merge_panels → panel.json（带 protocol_sha256）
             → compare_panels（按 seed 配对 bootstrap + 共同存活子集 M1）
```

**一句话**：3 小时作业 ≈ **600–725 轮 × 约 1.03e5 决策 ≈ 6–7.5e7 决策**，
约等于论文一个 stage（3.1e8）的 **1/4–1/5**。

#### C2 优化器 / 调度器（`PPOTrainer`）

| 参数 | 值 |
|---|---|
| 优化器 | `torch.optim.Adam(model.parameters(), lr=6e-06)`（**betas 0.9/0.999、eps 1e-8、weight_decay 0** 全默认） |

| `max_updates` | **300**（单位=训练轮，不是优化步） |

| 精度 | 前向 `--amp bf16`；loss（CE/KL/熵）强制 fp32；`backward` 在 autocast 外 |
| `compile_train` | **0**（不 torch.compile） |

#### C4 信用分配（`compute_gae`）

| 参数 | 值 | 含义 |
|---|---|---|
| `gamma` | **1.0** | 不折扣（奖励只在终局） |
| `lam` | **0.995** | GAE λ |
| 末步 | `next_value=0`，`last_adv=0`（**不做 truncation bootstrap**；截断局整局丢弃） |

| **已知偏差** | 每局约 200–242 决策 ⇒ **首决策只拿到终局信用的 30%**（`0.995^241`）⚠ |

## 6. 与审计结论对应的"配置风险清单"

| 风险 | 对应配置 | 建议 |
|---|---|---|
| **名次奖励贴随机**（1028 局 mean 4.55、前四 46.7%） | 场地 T12–T16 = 模型的 2.2–2.6× | 场地强度需你定；研究见 `TRAINING_OPPONENT_DESIGN_20261117.md` |
| **只奖前二**把 top4 换成了吃鸡（7.2%→14.2%，前四 −2.8pp） | `--rank-utility-table` | 是你的设计选择，未动；只想提醒它与"稳前四"不是同一目标 |
| **首决策信用只剩 30%** | `gamma 1.0 + lam 0.995`（242 决策/局） | 建议单独一轮 A/B（λ→0.999/1.0），改前先记录 `adv[0]/adv[-1]` |
| **教师项相对强度随采样漂移**（小批量可达 ~100×） | `teacher_loss_normalize=labeled` + `coef 0.1` | 已可观测（`teacher_label_share`）；`valid` 口径待对照实验 |
| **后期乘法成长缺失**（金卡 0.97 vs 2.55、留存增重 +87 vs +690、每格 atk 123 vs 598） | 上述 15 个模块**全关**（bc/board_problems/retained_growth…） | 场地修好后单独开一轮做第二变量 |
| **动作空转**（T12 每回合 move 5.02 / freeze 1.91，两个 cap 都打满） | `move_cap 5`、`freeze_cap 2` | 可试"cap 收紧"的便宜 A/B |
| **`max_updates 300` vs 实跑 600–725 轮** | 每个作业后 300 轮都在 lr=5e-6 平台上跑；且每个新作业又从 6e-6 起步 | 属配方；如需真正单调退火要改 `--trainer-state` 策略 |
| 评测名次与板面脱耦 | `EVAL_PROTOCOL` 的"结果刻度" | 已按你的口径把名次降为参考、主看 M1（工具已支持两种 M1 口径） |
