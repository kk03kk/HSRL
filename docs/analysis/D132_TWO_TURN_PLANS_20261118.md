# 两回合经营方案的离线学习与配对验证

## 问题与事前约定

D-132 观察到真人交易偏好能跨阵容预测，但直接改一笔买卖未确认自然局收益。本轮固定父模型 v1.4-r1，检验从真人学习的交易计划能不能在新商店中连续兑现，以及学习者能否判断何时应保留原策略。批准预算为 256 个自然中局、每源 8 组相同未来、每组 3 条路线，上限 6,144 次完整续局。

事前方案将 128 个 v14 来源用于收益拟合，另 128 个 v14hold 来源用于验收；每组依次平衡 T7–8、T9–10、T11–12 三个窗口。在每个独立种子段按顺序打自然局，取第一个父策略与建议在指定时段出现交易分歧的局面。记录筛查分母。分歧来源的收益适用于出现这种机会的局面，全部自然局的效应需要独立整局验证。开局没有指定英雄、组件、阵容或战力。

在每个来源比较父策略、只采纳首步、采纳至下回合结束三条路线。它们从相同实体、商店、金币、动作计数和守卫开始。每个未来用相同 RNG 起点与对手抽样种子，动作分化后商店与战斗可随之分化。后两路线的第一步必须完全相同；连续路线在每次新决策重读状态，期满交回父策略。各分支一直打到整局结束。原名次效用是唯一选路目标。在同一批配对未来中，“首步减父策略”加上“连续减首步”正好等于完整计划的效果。

两个选择器用事前固定的种子 13211、13229，各从 128 个拟合来源不放回抽取 112 个。它们使用公开的血量、经济、回合、牌面配套、卖掉的身材占比、父模型与提议的相对偏好等 12 项特征。岭回归惩罚 30，预测整局效用差大于零才采纳。门槛是两个固定选择器的等权平均在 128 个独立留出来源上，相对父模型的配对 95% 区间下界大于零，且点估计优于逢分歧就采纳。抽样单位是来源局，同一来源的八组未来先平均。只有通过才启动 512 个新配对种子的自然整局评测。[事前冻结的配置](../../config/research/d132-paired-plans-20261118.json)

## 真人示范与迁移

既有动作导出器在同回合按动作类型排序。这会改变购入、打出与出售的先后关系，也会影响依赖“本回合已打出”的旧特征。因此 D-132 以前从该表得到的历史特征效果需要重新验证。此次回到 build 255790 的 Firestone XML，按每个行动块开始的原始序号排序，并逐局校验原始压缩文件的 SHA。买卖要求所选实体及牌名和槽位相符；买入要求该操作块内可用金币净减 3，卖出要求净加 1 且满七个随从。特殊折扣与一次性额外收入没有进入交易标签。可见金币按资源总量加临时资源减已用资源读取。样本是精选回放，胜率有选择偏差。

原始队列为训练拆分 742 局、独立评测拆分 69 局。对每个交易候选，冻结父模型的卡牌表示，加入当前配套、手牌、金币和最近两个招募回合的有序操作。小网络在可辨识候选中预测选牌，用下一回合入战牌面是否拥有同一普通/金色基础牌族作为辅助目标（权重 0.25）。后者仅用于拟合标签。两层隐藏宽度 32/16，AdamW 学习率 0.002，12 轮，按来源游戏等权。遮掉历史的对照保持网络和训练相同。所有恶魔标签整局均从拟合中留出；恶魔牌可出现在其他阵容。收益选择器不读阵容标签。

## 留出局面如何选择

采集时在 v14 训练库筛查 553 局，在 v14hold 留出库筛查 573 局，各取得 128 个来源。训练场卖 / 买分歧为 114 / 14，留出场为 121 / 7；涉及 66 / 74 个英雄。留出时行动前的主导种族按至少三张且唯一多数计，机械 42、龙 25、海盗 9、野猪人 9、元素 4、畸变 3、恶魔/鱼人/亡灵各 2，另有混编 30。该分层只描述当下的棋盘，无法从这些小组推断对每一种攻略阵容均能迁移。256 个来源清单 SHA 为 `973b3b6acb9e8627e53674719184b11ed746498bbb7c5f7e1c0885d3feb4c802`。

完整续局共 6,144 次，其中验收集 3,072 次。两个选择器分别在 128 个新来源中采纳 62、70 次；共同采纳 51 个，共同放弃 47 个，30 个意见相反。各自相对父策略的原效用差为 −0.0158 [−0.0524,+0.0188]、−0.0105 [−0.0463,+0.0225]。等权效用差为 **−0.0132 [−0.0484,+0.0197]**。相对总采纳的差为 +0.0081 [−0.0259,+0.0429]，通过第二项点估计要求，但第一项下界要求未通过。平均名次差为 −0.018 [−0.096,+0.060]。实际选中的机会中，完整计划相对父策略平均 −0.0256；放弃的机会如果采纳，平均 −0.0166。两个数按两个选择器的实际选择次数加权。这解释了为何比总采纳少亏，仍未学出可靠的取舍。

## 第一步和后续经营分别贡献了多少

|原名次效用的配对差|每次均采纳建议|按两个选择器采纳，计入全部来源|
|---|---:|---:|
|只改第一步，相对父策略|−0.0264 [−0.0739,+0.0187]|−0.0102 [−0.0433,+0.0194]|
|继续运营，相对只改第一步|+0.0051 [−0.0146,+0.0273]|−0.0030 [−0.0155,+0.0097]|
|完整两回合方案，相对父策略|−0.0212 [−0.0711,+0.0275]|−0.0132 [−0.0484,+0.0197]|

在 1,024 组留出配对未来中，连续执行有 274 组在第一步后再次改变动作（26.8%），其中 146 组到下一回合还改变选择（14.3%）。允许连续接管的时间跨度充足；策略产生的行为差异大多集中在第一步。全采纳时的负点估计主要来自首步，后续的正点估计很小；没有证据认定首步一定有害、后续一定有益。

两个具体例子按两个选择器均同意的来源中，预测收益距组内中位数最近来选，不按对局结果挑选。在种子 `81105100` 的 T11 龙场，生命加护甲 17，两者均建议改卖金色 Fire Baller、保留 Heroic Underdog。八组未来的首步效用差 +0.0188，后续差为零。在 `81106300` 的 T9 畸变场，生命加护甲 39，两者都拒绝改卖 Fetid Corroder，继续卖父策略选定的 Nightmare Corroder；八组未来的平均效用没有差异。前者示范了一笔看得懂的小改进，后者提示“选择放弃”本身不足以证明模型预见了损失。

**结案。** 留出门槛未通过，按用户约定停止。512 个配对种子的自然整局与正式长训均未启动，NUS 无运行或排队作业。保留校正顺序的真人数据与冻结模型头供复核。当前证据支持交易历史含有跨阵容的选牌信息，未支持把它扩训成可自主取舍的整局策略。
