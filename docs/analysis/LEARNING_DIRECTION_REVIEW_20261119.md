# 真人场长训、教学迁移与新版本路线复盘

**研究判断（D-149，2026-11-19）。** 第 3265 版仍是当前版本经独立种子检验的通用基线。自然 PPO 有能力优化即时战力、存活和名次。跨回合产出、保留与兑现稀有资源，在自然起点的探索覆盖和收益估计方面仍有缺口。攻略提供的机制课程已产生可复现的局部技能，目前没有充分证据认定教学后接 PPO 的整局优势。新版本建议保留自然 PPO 基线，重点验证由可见机会出发、可转型也可放弃的模拟器课程，逐步增加模型自己发现和验证的方案。

## 新版本的研究选择

1. **先建立可比的自然环境。** 核验新版机制、动作及卡牌身份，按对局来源划分新真人库，检查长尾覆盖与可恢复性。对未覆盖的回合明确采集补足或单列经过验证的对手协议。直接悄悄复用上回合战团会改变赛制。将旧通用基线按语义兼容性迁移测试，按新版独立评测确定起点。
2. **让发现候选方案的来源多元化。** 用攻略提供第一批机制假设，同时保存无教师采样中异常高增长、经济正循环和相似入口下失败的真实轨迹。按局面归档，回到承诺之前，改变供给、血量和竞争阵容，用共同随机未来比较继续原阵、低成本试用、投入或退出。候选生成与盲验未来分开，策略只使用当时可见信息。训练一个通用策略；有跨局证据的连续方案、包括学生胜过教师的方案都可以成为新示范。
3. **先补选项覆盖，再交给整局价值。** 从给足时间的晚期局面将入口逐步移到自然中局、正常开局。以资源产量、未来可兑现身材、机会成本作辅助预测，独立留出状态检验其价值，教师影响随收益证据递减。日常部署可采用无搜索策略。已有反例显示酒馆暂时无元素时，不同永久元素商店增益可以生成完全相同的当前观测；先补玩家可见历史，同时做有无历史的配对验证，再决定是否更换网络。T12 速度、T15–T18 机制能力、自然机会接受与拒绝、整局竞争力分别记录。
4. **算清攻略方案的净收益。** 从同一新版基线比较直接 PPO、教学后的学生、教学后接等量 PPO，资源允许时同时报告总 GPU 小时（含生成/筛选示范）与有效自然决策数。固定独立对手与种子，训练种子复核只给有希望的方案。门槛包括整局名次效用/前二、弱势旧打法的回归、开放该族时的选择质量和非目标族的迁移。若只有课堂改善，保留技能和证据，扩展自然选择课程；若两种初始化经等算力得到相同成绩，优先实现更简单者。后期以模型自动发现、且经独立未来验证的高收益方案比例，以及不提供该族攻略时在全新机制上的成绩，衡量对人工知识依赖是否下降。
