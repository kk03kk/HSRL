# 自然运营与下一轮长训准备

## 研究起点

上一轮 69,691,656 决策正式训练从 v1.3-r3 得到 v1.4-r1。随后 48,379,721 次短训采样和
条件续局证实了金色组件齐备时的成长收益，但没有证实稀有局面的学习能改善自然整局。
本次从已封存参考 v1.4-r1 分叉，针对会改变长训投入的三个判断开展验证。前轮研究原文见
[阶段综合报告](RESEARCH_STAGE_REPORT_20261118.md)。

## 有限动作预算下，收尾要不要提前

以旧开发集的有历史残差为对象，针对 T12 已用 95–99 动作、满场且准备卖牌的第一个局面，
直接执行合法 EndTurn，与封存策略继续至本回合结束的局面做原生战斗对照。每个触发局面使用 32 个
相同未来随机流。98 次续局中有 32 次触发，涉及 25 个独立来源。作业 1160693 完成 1,024 对战斗。
按触发来源聚类，提前收尾战斗分差 −0.0075 [−0.0247,+0.0034]（胜 1，平 0.5，负 0）；
战后生命差 −0.020 [−0.205,+0.123]。保留正常运营，教师不加入这条提前结束规则。
此处固定已实现的招募路径，改变战斗随机性；结论仅针对本回合战斗及该候选的条件起点。

## 校正自然局的法术行为

旧观测性指标从公开视图的 `type` 字段识别法术，但实际评测入口传入的原生手牌及商店使用
`item.Spell`、`item.Minion`。旧面板相关动作全部被归入随从。1160743 复算 v1.4-r1 的 64 个旧开发整局，
覆盖全部 12,904 个动作。实际购买 913 次法术及 579 次随从，打出 2,243 次法术及 1,345 次随从，
另有 438 次磁力。仅 T9 起就有 706 次法术购买、1,631 次施法、401 次磁力。
这给出了常见运营动作的真实覆盖率。单凭施法次数仍无法判断施法目标和保留时机是否正确。
修正已覆盖实际评测入口，定向测试 8 项通过，旧封存面板保留。

## 为什么下一笔算力投给原场自然 PPO

两次开发评测使用互不重叠的 192 和 256 个游戏种子。下表对同一父模型与两个固定的原配方终点
作事后合并描述，每个策略正好 448 局。逐回合 M1 为当回合幸存战团总攻血的中位数。

|策略|平均名次|前四|冠军|T12 M1 / n|T14 M1 / n|共同 T9–T12 成长差，相对父模型 [95% 区间] / n|
|---|---:|---:|---:|---:|---:|---:|
|父模型 v1.4-r1|4.688|200/448|50/448|1395 / 294|2806 / 147|基准|
|原场、原奖励 A|4.560|201/448|61/448|1385 / 315|3057.5 / 140|+0.003 [−0.060,+0.065] / 244|
|原场、原奖励 B|4.460|227/448|68/448|1476.5 / 312|3121 / 167|+0.011 [−0.054,+0.076] / 230|

相对父模型，原配方 A/B 的 448 局配对名次差为 −0.127 [−0.335,+0.078]、−0.228 [−0.458,+0.007]。
第一批 192 局的名次差为 +0.109 / −0.099，第二批 256 局为 −0.305 / −0.324。两次短训都增加了
合计冠军、T12 存活局数和 T14 幸存者 M1；A 到达 T14 的局数反而少了 7 局。共同幸存成长仍待确认。
这支持用两个新采样种子测量原配方在更长时程下的成长，不足以直接复制上一轮约 7000 万决策的投入。

**扩训判据。** 两个 1200 万终点与父模型在 512 个新开发游戏种子上各评一次，三者完全配对。
逐组报告 T9–T14 的 M1、样本量、到达率、共同存活成长、名次、原效用、前四与冠军。
要支持进一步投入，两个训练种子各自的共同 T9–T12 成长点估计须为正，两个估计等权平均的配对
95% bootstrap 下界须高于零。两组各自 T12 到达率至多下降 3 个百分点、原名次效用差均须非负，
并要求等权平均名次差的 95% 上界低于 +0.20。3 个百分点和 0.20 是此次预算决策的容忍量。
bootstrap 以游戏种子为单位，同步重采三个模型，保留共享父模型的相关性。两组共用初始权重，
区间只量化游戏种子的波动。任一门槛未满足就封存该轮；满足门槛也只形成下一次算力建议。
该开发面板不占 E1 或正式保留种子，不据此变更冠军或实机 pin。
