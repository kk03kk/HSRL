# 自然运营与下一轮长训准备

## 研究起点

上一轮 69,691,656 决策正式训练从 v1.3-r3 得到 v1.4-r1。随后 48,379,721 次短训采样和
条件续局证实了金色组件齐备时的成长收益，但没有证实稀有局面的学习能改善自然整局。
本次从已封存参考 v1.4-r1 分叉，针对会改变长训投入的三个判断开展验证。前轮研究原文见
[阶段综合报告](RESEARCH_STAGE_REPORT_20261118.md)。

## 有限动作预算下，收尾要不要提前

以旧开发集的有历史残差为对象，针对 T12 已用 95–99 动作、满场且准备卖牌的第一个局面，
直接执行合法 EndTurn，与封存策略继续至本回合结束的局面做原生战斗对照。每个触发局面使用 32 个
相同未来随机流。98 次续局中有 32 次触发，涉及 25 个独立来源。作业 1160693 完成 1,024 对战斗。
按触发来源聚类，提前收尾战斗分差 −0.0075 [−0.0247,+0.0034]（胜 1，平 0.5，负 0）；
战后生命差 −0.020 [−0.205,+0.123]。保留正常运营，教师不加入这条提前结束规则。
此处固定已实现的招募路径，改变战斗随机性；结论仅针对本回合战斗及该候选的条件起点。

## 校正自然局的法术行为

旧观测性指标从公开视图的 `type` 字段识别法术，但实际评测入口传入的原生手牌及商店使用
`item.Spell`、`item.Minion`。旧面板相关动作全部被归入随从。1160743 复算 v1.4-r1 的 64 个旧开发整局，
覆盖全部 12,904 个动作。实际购买 913 次法术及 579 次随从，打出 2,243 次法术及 1,345 次随从，
另有 438 次磁力。仅 T9 起就有 706 次法术购买、1,631 次施法、401 次磁力。
这给出了常见运营动作的真实覆盖率。单凭施法次数仍无法判断施法目标和保留时机是否正确。
修正已覆盖实际评测入口，定向测试 8 项通过，旧封存面板保留。
