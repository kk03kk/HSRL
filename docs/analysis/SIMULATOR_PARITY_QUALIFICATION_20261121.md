# Player150 37.0.3 模拟器校验与修复

2026-11-21。以 3286 的冻结 Player150 引擎为对照，校验高频招募、战斗先手、伤害上限和真人战团注入。用同版本原始事件确认差异，在独立源码与安装目录验证修订。

## 已修复的差异

| 规则 | 对照与修订 |
|---|---|
| 战斗先手 | 旧引擎在两边随从等量时总让高酒馆等级先手。初查 24 局原始 XML 的 51 场等量、不同等级战斗中，低等级方先手 21 场。第二批 32 个不同原局按原局摘要选取，选样时未使用先手标签，76 场中高低等级各先手 38 场。修订后随从多的一边优先，数量同等时两边随机；独立检查不同等级、等量盘面及数量不等盘面。 |
| Talent Scout | 官方记录没有己方伙伴时无法打出。旧二进制允许打出。普通与金色现在都需要战团中的伙伴，只有商店有伙伴时也拒绝，合法动作掩码和执行路径共用判定。 |
| 副厨贴纸 | 两张贴纸只提供一次额外英雄技能机会。原代码把次数按张数累加。验证 0、1、2 张贴纸的可用次数。 |
| 吞噬之爪与乌祖尔贴纸 | 按本版官方已知问题，乌祖尔贴纸直接触发的吞噬不获得吞噬之爪的额外身材与关键字。其他来源的吞噬正常获得奖励，两个分支均测试。 |

卡牌差异来源为[暴雪已知问题清单](https://us.forums.blizzard.com/en/hearthstone/t/370-highlights-known-issues/153567)，规则基线为[官方 37.0.3 热修](https://us.forums.blizzard.com/en/hearthstone/t/3703-hotfix-patch/168317)。本地源码在 `codex/simulator-parity-20261121`。先手原始事件审计工具可通过 `git show codex/simulator-parity-20261121:tools/audit_firestone_openers.py` 查阅。

## 外部证据与覆盖

- 先手以原始 XML 的顶层攻击块、可定位的双方战团实体、回合和战斗阶段为准。Firestone 的 `wentFirstInBattleOverTurn` 与可对齐原始事件经常不一致。共复查 597 个两边有存活随从的可定位首刀，均处于战斗阶段。15 个战前快照中较少一方打出首个普通攻击的情况里，14 个在首刀时已等量或反超。剩余一局在正常首刀前发生 Wingmen 立即攻击，保留为特殊开场证据。
- 24 局真实 XML 中，早期常规样本的买随从 39/39 花 3 金、卖随从 8/8 得 1 金、刷新 6/6 花 1 金、冻结 8/8 免费。全时段另有免费刷新、级别和经济效果等上下文。该抽查只覆盖观测到的动作。
- 226 场原始战斗日志的 5／10／15 上限值均符合回合分段。64 场能配对到启用上限和英雄伤害增加的案例中，没有看到单次伤害超过对应上限。预汇总伤害和原始英雄事件有差异，审计使用原始标签与实际伤害。[伤害上限定义](https://hearthstone.blizzard.com/en-us/news/24163459/31-2-patch-notes)
- 348 局原有真人留出库的 6,845 帧在新引擎上逐帧复验成功，卡池守恒、注入与可见字段均通过。它的原始存储和摘要继续保留，验收回执在 `artifacts/runs/nus-simulator-parity-real-field-20261121-01/qualified.json`。
- Volumizer 在 353 局、8,660 份可见战团中出现 316 帧，金色为 14 帧，分属 12 个原局。官方列出的特定三连、复制与光环异常触发条件待确认。Malchezaar 与 Leaf Through the Pages 同时可见于 4 帧，异常刷新扣数语义待确认。全隐藏状态、极少数卡牌交互和真实计时仍需要按用途单独验证。Player150 的 150 步、换位和冻结预算沿用原训练配置。

## 验收结论

候选 `6340d5120e9ddda5` 通过本轮高频规则与训练接入验收，可作为后续 NUS 训练的规则基线。覆盖范围内，已解决所有经原始事件或官方本版记录确认、可能影响训练的明显差异。剩余的特殊卡牌交互、真人隐藏状态和客户端计时待确认。训练接入只验证了 8 局和一轮 PPO，长期学习曲线和正式棋力待确认。
