1. 作业 1167182，冻结源码 `666275e`。在训练库用 256 个种子按预设方案分别取 T1、T6、T8 或 T10 中局，两种前缀策略均衡分配。252 个起点实际可接管，另外 4 个在指定回合前已结束。每个中局两原策略在两个配对随机未来各自运营至终局，合计 1,008 条评分续局；另用原始随机未来生成 504 条独立于评分的示范。按原名次效用选教师，差为零时沿用群友示范。135 处选群友（含 13 个平局），117 处选 3265。
2. 两臂共用同一候选轨迹库与源局抽样序列。每个源局、每种示范最多保留 144 个有真实选择的决策。每批 96 行，24 行固定来自 3265 自身轨迹，余下 72 行普通组取群友示范，筛选组取该源局胜出的示范。对合法动作概率做交叉熵，用 0.35 权重的 KL 约束学生的名次分布接近原模型。各 1,600 步、153,600 行采样曝光（包含重复），AdamW 学习率 2e-5，梯度范数上限 1。两个终点均直接封存，无开发集挑选。两臂拟合分别用时 94 和 95 秒；共享生成库令比较聚焦示范选择，单跑普通组可以省去评分续局。
3. 作业 1167194，252 个中局各加一个从未用于选示范的随机未来。筛选相对恒用群友的平均效用差 +0.035，配对 95% 区间 [−0.056,+0.123]。选群友的 135 个起点上，群友相对 3265 的盲验效用差平均 +0.442；选 3265 的 117 个起点上，群友相对 3265 平均 −0.076。两组的排序有信息，但筛选规则相对恒用群友的额外收益尚不确定。
4. 作业 1167339，用另一批 64 个训练库种子，让两原策略分别打完整局，在同一观测和合法掩码上比较三份 HSAI 权重与教师的分布。教师自身访问状态共 7,694 个决策，3265／普通／筛选的首选动作一致率 26.4%／52.2%／46.2%，教师至三者的平均 KL 为 6.40／0.71／1.13。3265 访问状态共 7,070 个决策，三者一致率 27.2%／34.1%／30.5%。单步动作含具体摆位等细分，因此相异动作不能一概视为策略错误。

### 从准备到兑现

258 局开放野猪人。取 T6–T8 任一回合场上有健身搏猪或棘刺挖掘工为准备；在同一局从 T12 起至少两个不同回合测得骑士抉择引发的正身材增长为后续兑现。顺序均为 3265／普通／筛选／教师：

- 单看 T6 有准备组件的局数为 29／74／51／145；T6–T8 有过准备的局数为 39／126／67／233。
- 同局从准备接到后续兑现的局数为 0／3／2／116。全时段至少两个回合实际触发抉择为 5／15／8／159。见到可购买的普通骑士与实际购买的局数为 90→3／52→16／79→14／142→139。各策略自然产生的商店、存活和机会不同，购买比率不能解释成同状态的因果效应。
- 268 局开放元素。以 T6–T8 见到己方场上有艾泽里特或魔网浮灵、T12 起至少两个回合有正收益吸收作代理，连起准备和兑现的局数为 0／5／0／17。这个代理不覆盖所有元素运营，也不能把同一局的全部成长归因于吸收。

## 长局边界与证据

原严格同回合协议 `3af5631bb2190a5dd862298fe7b2f1974f052c9e3b1e460975b5d097386a03ae` 的作业 1167183 中，种子 186730138 的 T19 决赛双方各剩 3 血，留出库覆盖至 T18。保留现场，停止该作业。冻结权重、种子、对手库及 T1–T18 抽样规则，全量在新目录重跑。作业 1167325，源码 `b685302`，独立协议 `ec900f2c14cd9922d2b2e9b2f68835b703d57090c9e68d666f4620930351bcd4`。该协议只在超出库末且模型仍存活时允许使用最后观察回合的真人棋盘，逐局计数。严格作业已完整落盘的 230 对四臂记录，重跑时全部复现名次、每回合双方模型行为指标和盘面记录。最终仅群友在上述种子需要延用，获得第一；在原协议下其名次只能判为第一或第二。教师冠亚军两种取值下，相对 3265 的平均效用差范围 [+0.1784,+0.1797]。两学生和原模型的全部自然局、全部已抽取的同状态对照均不受尾部近似影响。

训练与两份模型在服务器 `artifacts/runs/nus-peer-distill-20261119-1`，见 `ordinary/`、`filtered/` 的模型、manifest 和模型卡。最终逐局和同状态原始证据在 `artifacts/runs/nus-peer-distill-assess-20261119-2`。盲验和动作诊断分别在 `artifacts/runs/nus-peer-filter-blind-20261119-1`、`artifacts/runs/nus-peer-fidelity-20261119-1`。

## 决策

两学生均未通过进入短 PPO 的门槛。筛选降低了整局退化，却减少了新成长路线的尝试。普通蒸馏能学到部分准备和教师偏好，未重现教师的跨回合兑现能力。现有结果不能断言原因完全是训练量、分布偏移或网络容量。若继续迁移，先用普通学生自己走出的自然局，在准备成功但核心未承接的分歧处，检验教师接管若干回合能否同时挽回后期兑现和名次；若能，再考虑只对这些状态补标。短训、长训与实机模型均不切换。
