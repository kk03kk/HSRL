# HSAI 持续强化学习研究路线

2026-11-21，研究提案。适用范围为当前 Player150 及下一版模拟器。本文给出后续实验的选择与停止条件，现行训练配方、正式榜单和发布决定仍以各自冻结记录为准。

## 一、研究决策

保留 3286 作为第一个学生和回退基线，维持一条 HSAI 管理的训练主线。群友 01 原版、R1、群友 02 的 0750、自有 3265 各自冻结。每位专家可以提供对手、局面和候选打法。要进入学生，打法须先在学生会走到的局面中证明价值。之后逐渐撤掉教师，让学生用自己的整局回报学会何时投资、转型和退出。后续新来的模型也走这条入口。

项目跨版本应持续维护五样资产：能从历史回放检验的玩家视角接口、分来源的对手与考试库、带前置机会和独立续局结果的决策样本、包含失败对照的能力记录，以及可以完整恢复的学生。衡量体系的长期指标，是同等决策数和算力下新版本达到固定基线所需的时间、相对于无教师 PPO 的额外收益，以及连续两代新增和保住的能力。只有一个强 checkpoint 时，这三个问题都无法回答。

## 四、选择训练方法

1. **以现有 Player150 PPO 为起点。** 网络和恢复链已可用，学生有自己的玩家视角和完整的 245 动作。首轮沿用冻结的名次效用、动作预算、学习率与 KL 基线，以同预算 PPO 作为对照。按名次而设的效用隐含争一和保分的权衡，后续若要改变，应单独比较整条名次分布。升本、核心卡数、身材与流派数作为诊断指标。模型的目标是从当时信息选择最有价值的经营路线。非传递对局、隐信息、商店与战斗随机性都使“某套阵容唯一正确”难以成立。[现役训练设计](PLAYER150_FIVE_20261120.md)
2. **先验证教师在学生局面里能帮到哪里。** 从学生自然访问的局面采样，保存原状态和真实公开历史。比较维持原策略、教师接管一个有限经营窗口后归还学生、教师持续到终局三个分支。若只有整局接管有效，就定位后续承接失败的地方；若相同公开观测对应不同必要决策，先查历史和字段可见性。0750 的循环状态按实际前缀的已执行动作逐步重建，尤其是来源组。先在教师自己的前缀上证明可重复，再在学生前缀上验证；不能用全零隐状态冒充分叉时的历史。[0750 双阶段策略实现](https://github.com/asd-HS/hearthstone-bg-agent/blob/9b96cf0c8788d8f3f6caf65b1408b11f8fbee3b3/src/hearthstone_bg_agent/model.py)
3. **把收益明确的一段教给学生。** 只在玩家可见、双方语义兼容的局面给示范，用合法共同动作上的软分布或完整决策片段做辅助训练，保留学生原有的换位能力。对多个教师冲突、独立未来分不出高下的局面，保留多种可行选择，不强制打唯一标签。普通自然状态与原有优势状态同时进入保留样本。用学生自己的新轨迹做一次有针对性的补标，然后减弱教师损失并彻底撤掉教师，在学生自己采样的整局上做 PPO。示范进入监督项，历史专家轨迹不冒充当前 PPO 的在线样本。若只提高动作匹配而没有自然局兑现，停止扩大蒸馏。[Kickstarting Deep Reinforcement Learning](https://arxiv.org/abs/1803.03835) · [HSAI 蒸馏反例](PEER_DISTILLATION_20261119.md)
4. **让系统自己发现教师没有的打法。** 以局面复原和离线模拟探索学生反复出错的分歧，例如低血时冲六、已有经济引擎时过早卖核心、决赛拆成长位换针对卡。候选来源包括策略的几个合法备选、旧模型、真人选择与简单战术规则；用未参与挑选的随机未来估值。保留有收益的分歧，也保存“这次不该转”的反例。先用已有计算节点上的状态分支能力，部署时继续单策略推理。只有这些候选在独立未来反复胜过教师，才值得训练更复杂的价值模型或把搜索带入执行时限。[已有的独立未来检验](ADAPTIVE_DECISIONS_20261120.md)
5. **对手先保真，再逐步引入会经营的席位。** 真人快照训练场便宜、可控，可用于大吞吐经营学习。按实际遇到的回合、血量压力、种族、来源水平和战斗胜负校准，观察 T8–T12 到达与回报是否仍有区分度。用冻结 R1、3286、0750、自有旧策略及 bot 组成会自主经营的小型历史对手池，轮换焦点席，测共享卡池、争抢、侦察和决赛针对。先作为独立考试；若快照上进步、互动场持续退化，再将固定比例的动态局加入训练，对比等决策、等 GPU 小时的成效。训练方可调难度，考试权重和来源提前封存。长期保留克制关系矩阵，按覆盖缺口加入新对手。无需一开始养八个同步学习者。[AutoTavern §6 与附录 B](https://arxiv.org/html/2610.33845v1) · [AlphaStar 的历史对手与克制关系](https://doi.org/10.1038/s41586-019-1724-z)

**方法取舍。** 同代同结构下直接续训用作必要对照；跨观察、跨版本、重置优化器时明确标为分叉。两位群友的结构、卡槽、历史和动作语义不同，跨网络平均参数没有可靠含义。同谱系 checkpoint 平均也只能作为另外的同场实验。常驻多模型投票会增加时延，并可能让前一个模型的投资被下一个卖掉；教师接力的理想上界先在离线同状态测试。公开历史增强、循环学生或条件策略头只在“现有观测预言不了、公开历史能补，且整局收益受限”的对照成立后再投入。要验证方法能独立于外援，在下一版保留一个仅用自有 3265 兼容部分或从零初始化的低预算参照，比较同算力学习曲线，登记全部权重与示范来源。

## 六、判定进步、遗忘与实机可迁移性

**第一个赛季周期要验证两次不同来源的提升。** 第一项来自冻结专家的发现海盗，证明外部专长能进入主学生。第二项由 HSAI 从自己的败局提出，例如面对末段巨型单体时是否值得卖掉成长位，冻结两种合法处理、用对手不确定性和独立战斗结算产生标签，拿撤掉搜索和教师的学生去打完整局。后者能在无新外部权重的情况下通过验收，才有第一份自主发现的证据。到下一次换版再做同预算迁移对照，报告恢复速度与遗忘。若系统只能复制旧玩法，下一笔算力优先用于候选动作多样性和对手覆盖。

- **来源隔离。** 训练、调参、一次性确认按原始比赛 ID、回放来源和版本切开。同一原局的帧和恢复点只进一个集合，重复种子与相同对手轨迹单独标记。另设跨来源场以评估对手分布变化。候选、比较方向、预算和终点先冻结，尽量在一个评测批次内共享种子及座次。两个教学样本共用前缀时按原始局面聚类；多次训练另报训练种子间差异。
- **四类量同时看。** 逐回合总攻血 P50 和存活 n、共同到达 T9–T12 的对数成长；从开局起算的名次全分布、前四、第一、末二与到达率；有族可用→看见机会→决定投资→持续成型→机制实际结算→终局的逐级分母；以及对不同难度、阵容、人口策略的配对结果。条件成长和从开局起算的效果同时展示，避免把早死局剔除后误判进步。快照面板、八席自主模拟、真实客户端分别报告。
- **下毒与决赛针对单独算。** 只给上次见到的公开战团及其时效，抽取多个与已知信息相容的对手和战斗随机未来。比较继续堆身材、换一个针对位、先破盾、调整站位的胜平负、受伤和整局名次，统计误判对手时的机会成本。在巨型单体、圣盾、多频率召唤等对手类型上各留正反例。正式决策看不到模拟器的下家私有牌和未来 RNG。低身材赢下关键战斗也应计为学到的能力。
- **为下一版预定晋级原则。** 研发阶段允许“发现一种专项”单独入能力库。代替主学生则要求目标能力在独立自然局达到预设提升，撤掉教师后仍保留，并在既有强项、低血存活、两类外部场上通过事前约定的非劣检验；通用棋力提升需在预定主场有正向整局收益。示例容忍线为平均名次变差小于 0.25，配对 95% 上界也须低于该线。实际界值应按迭代成本与旧版波动先登记。策略复核的名次差标准差约 2.36–2.64，512 对的均值差 95% 半宽粗估为 0.20–0.23 名，96 对只够筛方向。若实际样本量不足以排除退化，保留为研究候选。保持旧协议的 M1 和增长曲线判据，新增奖惩、对手或准入条件另立新协议。既有 E1 不重开。
- **实机迁移独立验收。** 玩家输入形成于决策时刻，仅含可见信息。记录观察差异、合法动作与目标对象、预算内可完成步数、真实时延、已确认的服务器回执及未完成动作。训练可在离线使用额外状态做机制标注，学生推理不依赖它。已有 237 个历史点可合法推理，以及两局试验中的 87/90 项三方核对，是起点。对高操作密度海盗和磁力尤其应做历史限时影子回放。未来具备条件再做小规模人工执行/监督验证，所有掉线、超时与未完成局分别报出；真实棋力待确认。[上线前离线核对](PLAYER150_PROMOTION_20261121.md) · [实际时序及未确认动作](PLAYER150_LIVE_SPEED_20261121.md)

AutoTavern 论文中，同起点同预算换成现实校准对手后，主考试冠军率从 20.9% 升到 27.2%，难场从 10.3% 到 13.5%。这支持优先研究面对什么对手。论文报告的天梯结果来自其特定版本、真人按提示执行以及独立的客户端故障记录。HSAI 应学这种现实校准方法，自己的天梯表现仍要自己取证。[论文 §6、附录 B 与 D](https://arxiv.org/html/2610.33845v1)
