# 第二阶段路线（2026-11-13 13:10 定稿）：把群友模型当"配方参照"，HSAI 仍是主体

## 0. 判断（先说结论）

1. **继续以 HSAI 为核心自主训练**。群友模型只提供**配方假设**，不提供权重（无 forward、
   无引擎、卡表/属性/流派编码都拿不到），任何"加载它"的路线都不成立
   （见 `THIRD_PARTY_PPO_20261113.md` §3.3）。
2. 他们的成功**证明了**三件事，这三件才是要学的：
   - **8.0M 参数 / 4 层就够打到高水平** → 我们的 14.8M 不是容量瓶颈，问题在**流程与信号**；
   - **BC（行为克隆）初始化 → PPO** 是一条走通过的路；
   - **流派条件化（z，46 个流派）+ 动作掩码约束**是"后期阵容运营"的一部分，
     并且他们实测 `keep_start_board` 值 0.10–0.14 名。
3. 他们的成功**没有证明**：必须用他们的引擎、必须用固定名次效用、必须 46 个流派、
   必须 z 条件化。我们的 33 个流派攻略、名人场评测、6k/8k 真人战团库都是自己的资产。
4. **我们目前最大的流程不对称**：他们有 BC 阶段，我们所有 fork 都是纯 PPO。
   这是本阶段第一个要验证的东西。

## 2. 四条候选路线，按"证据强度 × 成本"排序

### P1（进行中，今天出结果）：受控 BC 阶段
**为什么**：他们靠它成功；我们没试过"独立 BC 阶段"（只试过 5% 辅助项）。
**怎么做**：`deploy/slurm/bc_pretrain.sbatch`，champion 起点、`mmr-min 6000`（≥8k 只有 60 局）、
`lr 3e-5`、`epochs 4`、**`anchor-beta 0.05`（默认是 0，对 champion 太危险）**。作业 `1129252`。
**验收**：BC 后的 checkpoint 直接上**真人场** 96 局。判据：
- 若 `mean_rank` 显著低于 5.4375 → 说明"人类动作先验"对我们有效，把它变成主线前置阶段；
- 若显著更差 → 说明**部分观测的 BC 不迁移**（这是我们数据与他们的根本差异），
  立刻止损，不再在 BC 上投入。

### P2（本周，零步位等价）：流派条件化 z（零初始化）
**为什么**：他们的 z 是"后期阵容运营"的一部分；而我们的痛点正是**流派选择与稳定成型**
（覆盖能到 0.5，但拼不完整、不会按目标转型）。这同时给我们一个**可评测的新能力**：
"指定流派 → 能否拼出"。
**怎么做**：模型加一个 `z_emb`（33×d，取自 `config/strategy_cards.json` 的 33 个流派），
**零初始化**加到 global token → 第 0 步与 champion **逐位等价**，可以安全地在现有权重上开训。
训练时 z 取自"入场那一帧真人所属流派"或随机指定；推理时可指定。
**验收**：①第 0 步 bit-identical（有单测）；②指定流派的核心卡覆盖显著高于不指定；
③真人场名次不退化。

### P3（本周，低成本）：`keep-start-board` 等价掩码
**为什么**：他们实测 +0.10–0.14 名；机理与我们的 churn 诊断同向（"缺的是投资不是购买"）。
**怎么做**：回合开始时记录己方战团，本回合禁止卖出这些随从（可配置开关、可设起始回合）。
**风险**：他们的确切语义未知（是"开局战团"还是"回合初战团"），所以我们两种都实现、
各跑一个短臂，用**真人场**判定。

### P4：把赢家送进长训
任何在真人场显著赢的配方（配对 CI 上界 < 5.4375）→ 6 小时长训接力，
每 8 段（≈2.7 h）用真人场复测，记录到 `RUNS_*.md`。

## 3. 明确不做

- ✗ 加载/迁移/蒸馏他们的权重（无 forward，形状也不匹配）。
- ✗ `board-target` 的 Σ 总量口径（已两次证否）。
- ✗ 再叠"可被单独满足"的过程奖励（G2/G4/H1 的教训）。
- ✗ 在没有真人场证据前做结构性大改。
- ✗ 为了试新方案取消正在跑的作业（H10/H11 跑满再判）。

## 4. 统计纪律（沿用）

- 主指标：**真人场 96 局 `mean_rank` 配对 bootstrap**，门槛 = champion 5.4375。
- 辅指标：bot 场四项（板面比值 / 核心卡覆盖 / 前期回归 / 名次）+ 阵容完成度时间线。
- 每个改动要么**零步位等价**（加零初始化参数），要么用**对照臂**隔离；
  报实验必须写清 `anchor-beta / anchor-iterations / anchor-beta-tail` 三元组（D-039）。
- 96 局的 `mean_rank` SE ≈ 0.15，**≥2 SE 或配对 CI 不跨 0 才算证据**。
