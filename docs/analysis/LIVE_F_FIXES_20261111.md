## 1. 已修复

### P1 目标续动作不触发（T7、T8 卡住，需人工指目标）

- **现象**：Activate 打开发动目标选择后，模型不选目标，局面停在"已选中未指认"。
- **根因**：`controller.py` 的目标续动作外层门槛只认视觉信号
  `snapshot['visual']['target_open']`。实机该 UI 没有给出这个信号，续动作永不触发；
  而内层本来就有服务端权威判据（`interaction.mode=='target'` + `view.pending==4`）。
- **修复**：外层门槛改为 `视觉 target_open` **或** `interaction.mode=='target' 且 owner 是我方
  且 pending==4`。内层原有授权/身份/候选集一致性检查**一条不放松**。

### P2 续动作不归位鼠标（T0 选英雄、T6 选饰品）

- **现象**：确认点击后指针停在面板中央；T6 正好压在神明展示框上弹 tooltip，遮挡取景。
- **根因**：确认分支裸发 `[('click', point)]`，没走 `geometry.plan()` 的收尾
  `move_pointer [0.96,0.91]`，其它所有动作都有。
- **修复**：确认计划补 `('move_pointer',[.96,.91])`。这类问题一次治两处（英雄/饰品/未来确认）。
