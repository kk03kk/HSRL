## 2. 今晚必须落地的 4 项修复

### P0-1 · 「重新连接」自动恢复（决定今晚成败）

现状：`lobby.py` 把 `重新连接` 当成人工凭证问题，永久拒绝。

修法：
- 新增显式识别器 `reconnect_dialog(rows)`：标题 `重新连接` 在 y≈0.23，
  正文含 `离线状态` / `连接中断`，且有 `重新连接` 按钮在 **y≈0.75、x≈0.41**；
- **点按钮，不点标题**（截图里标题与按钮同名，标题在 0.23，按钮在 0.756）；
- 安全条件（防止误点「取消」退出客户端）：按钮必须位于同一行的 `取消`（x≈0.58）**左侧**，
  且两者 y 差 < 0.02，且标题存在；任一不满足 → 不点；
- 沿用现有 `stable()` 两帧证据，不新造点击机制；
- 上限 3 次，退避 10 / 30 / 60 s；成功后必须重新验到大厅标题才允许点「开始」；
- 只有 `验证码` / `登录`（真凭证输入）才硬停并留证据。

### P0-2 · 静默看门狗 + 防空闲断线

- 硬阈值：`>90 s` 无新决策 → 记 `stall` 事件（含 phase / 等待类别）；
  `>180 s` → 做一次无输入的重新读取并记录；`>300 s` → **干净收局**（`close_game` 归档未决意图）
  并回大厅，不要等服务器踢。
- 目的：在断线**之前**把这一局变成"可解释的截断"，而不是"假终局 + 断线弹窗"。
- 系统层（必须做，否则整晚白跑）：
  - 电源计划 = 永不睡眠；
  - **显示器 = 永不关闭**（黑屏会让截图变黑、DWM 合成停止，等于整晚瞎）；
  - 关闭屏保；确认 Windows 更新不在夜间重启。

### P1-3 · S0 不再终结整晚

- **保持不变**：永不重发"结果未知"的输入。
- 改变**响应方式**：从"结束整批"改为"收局 → 归档未决意图 → 新建 match 目录重新开始"，
  每晚上限 3 次；超过 3 次才停并留证。
- 理由：昨晚 7 次 S0 每次都是 1 局就终结一批，是第二个吞吐杀手；
  而"放弃这一局"并不违反安全铁律（我们没有重发，只是放弃）。

### P1-4 · 名次语义修正（数据诚信，决定今晚数据能不能用）

- 只有拿到**终局证据**（结果横幅「第X名！」或 Power.log 明确结束）才写
