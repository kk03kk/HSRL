## 5. 为什么名次不动（今晚最有用的一个解释）

把四组数字摆在一起看：

| 观察 | 数字 |
|---|---|
| 策略确实在"动" | `anchor_kl` 0.014 → **0.36**（312 轮），`approx_kl` 稳定 0.015–0.022，`entropy` 只掉 0.08 |
| 奖励确实被优化了 | T8 存活 +3.2 pt、T6 板面 +13.1%（都是名次奖励推得动的量） |
| 但通往更好名次的路径**从未被走过** | 买法术 **0 次/局**（真人 0.46–1.51/回合）；S 级核心卡命中 **0.139→0.089** |
| 真人靠什么赢 | 中后期增长 ≈90% 来自养保留随从：T10→11 每随从 **+690**，我们 **+42** |

⇒ **不是学不动，是"奖励看得见的那部分"已经学完了。**
我们的场里 7 个对手全是赢家级战团，**吃鸡率恒为 0**，名次几乎只编码"多活一轮"；
所以梯度把策略推成"前期更厚 + 活得更久"，而真正能换到 4.x 名次的
"买法术 → 打法术 → 养随从 → 拼 S 级阵容"这条路，当前策略**一次都没走过**。

这也解释了今晚两类失败：**在同一信号上加大力度没有用**——
`Φ=log Σ` 塑形加大到 20 只是把 `adv_std` 打到 4.51（方差机器），
终局板面奖励加大到 35% 名次全距则教会它"拿板面换命"（显著更差）。
