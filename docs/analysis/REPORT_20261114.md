## 3. 判定标准（先登记，不改）

1. **硬指标**：真人场 `mean_rank` 配对 CI 上界 **< 5.4375**；
2. **机制**：留存增重 **≥ +150**/随从/回合（现 +40，真人赢家 +690）；
3. **分布**：T12 存活率 **≥ 0.45**（现 0.354）或 第 4–6 名占比 **< 0.60**（现 0.67）。

②或③达成 = 方向对（即使均值还不显著）。

### 3.1 统计分辨率（先说清能测出多大差别，免得把噪声当进步）

配对 bootstrap 的半宽随 `1/√n` 收缩：96 局实测约 ±0.40 名次，192 局约 **±0.28**，
768 局约 **±0.14**（面板内 base 与候选共用同一批对手与 seed，逐局配对后自由度大得多）。
所以今晚的硬指标只在"差 ≥0.3 名"时才可能显著；更小的差别只能靠机制指标（留存增重、
法术使用、T12 存活）和臂内趋势说话。**报告里不许把 ±0.28 的噪声读成"进步了 0.2 名"**。
