**推论（今晚最重要的结论）**

1. 在这个场里，**PPO 目标在 champion 邻域外与真实棋力反相关**。它推着策略走向
   "板面更薄、T10 更早死、但偶尔多熬一轮"的塌缩解，同时 `approx_kl`/`entropy` 一路塌陷。
2. **`anchor 0.02` 是护栏，不是枷锁**。今晚唯一"没有变差"的臂（`l4`@301）正是
   漂移最小的那个（0.34）；把锚放宽到 0.005 直接换来翻倍退化。
3. 因此 champion 的 5.30 不是"训得不够"，而是**这条曲线上的局部最优**；
   沿着它继续走只会更差。

### 4.3 否证记录（都是干净否证）

- **L5c 终局板面奖励 1.0 → 显著更差**（+0.45 名，CI [+0.156,+0.734]；相对自己父系 +0.52）。
  它**在自己奖励的那一项上也更差**（T12 板面 −21.9%、T13 −31.2%），
  因为终局奖励不区分"活 10 轮还是 13 轮"⇒ 学会了"当期板面换命"：T10 存活 0.781→0.661。
- **L5a 法术补贴 → 结构上不可能生效**：补贴只在"真的买了法术"时付钱，
  而模型的 `p(买法术)≈0`（不是被掩码挡：掩码每回合合法）⇒
  21 个冒烟迭代 `reward_shaping_mean` 恒 0.0、`spell_bootstrap_hits` 恒 0。
  正解是 `forced_tier` 那套**强制注入 + 被强制样本不进策略梯度**的范式（§5.79）。

## 5. 为什么名次不会变好——以及为什么"再训一点"会变差

把数字摆在一起：

| 观察 | 数字 |
|---|---|
| 策略确实在"动"，而且越走越自信 | `anchor_kl` 0.014→0.34（l4）→0.87（l5d）；`approx_kl` 0.0205→**0.0031**；`entropy` 1.61→**1.28** |
| 但真实棋力**单调变差** | 累计漂移 0 / 0.34 / 0.60 / 1.21 ⇒ `mean_rank` 5.30 / 5.37 / 5.97 / 6.21 |
| 它追求的是什么 | T8 存活 +3.2 pt 这类"多熬一轮"的量；同时 T10 板面 −33%、T10 存活 −14 pt |
| 真人靠什么赢 | 中后期增长 ≈90% 来自养保留随从：T10→11 每随从 **+690**，我们 **+42** |
| 那条路为什么没走过 | 买法术 **0 次/局**（真人 0.46–1.51/回合）；S 级核心卡命中 0.139→0.089 |

⇒ **不是"学不动"，是"奖励在把我们往反方向推"。**
这个场里 7 个对手全是赢家级战团、我们**吃鸡率恒为 0**，名次几乎只编码"多活一轮"；
优化它得到的是一个**板面更薄、更早死、但偶尔多熬一轮**的塌缩解。
`anchor 0.02` 一直在限制我们走多远，所以看起来"没变化"——一旦放宽（`l5d`），退化立刻翻倍。

这也解释了今晚几类失败是同一件事的不同表现：**在同一信号上加大力度，只会更快走到那个塌缩解**
—— `Φ=log Σ` 加到 20 是把 `adv_std` 打到 4.51（方差机器），终局板面加到 35% 名次全距是
"拿板面换命"（+0.45 名）、继续训练是 +0.675/+0.913。

## 6. 下一步（按证据排序，不按愿望排序）

   望远镜增量、每局上界 0.35）。这是第一个用有界增量形状直接给"阵容完成度"发钱的臂。

   目的是让"买法术→养随从"这条路第一次进到值函数与状态分布里。
3. **检验"场太强 ⇒ 信号退化"**：launcher 已参数化 `HSAI_HUMAN_BOARD_P`
