# 战团快速采集：按完整对局录入

2026-10-27。已按用户最新要求简化：**不用填来源、主播、录像时间或截图，不需要反复确认。** 原有记录和备份继续保留。

## 使用顺序

打开 http://127.0.0.1:8766/ ，或双击主根目录 `启动战团采集器.cmd`。

1. **每局一次：英雄、该局可用种族。** 点击“新局”开始下一场完整对局；系统自动编号，不要求姓名、链接等信息。
2. **每回合：回合数、酒馆等级、生命、护甲、从左到右的战场。** 攻血直接在卡片上修改，金色勾“金”，关键字和额外效果在选中卡片处填写。
3. **有才填：技能、全局战斗效果、战斗相关手牌。** 普通不参与战斗的手牌不必输入；若战斗依赖手牌数量或随机抽取候选，再补数量/候选。
4. **保存并下一回合。** 复用同局英雄、种族和上一回合阵容，只改变化，不弹核对步骤。返回旧回合后再前进，会进入已有的下一回合，避免重复建记录。

自动保存；刷新后继续上次选中的局和回合。Ctrl+S保存，Alt+N或Ctrl+Enter进入下一回合。搜索卡名后Enter选第一张，开启连续加牌可快速追加；“整排填入”支持 `5/7 12/18 20/20` 或每张一行。

搜卡会带出参考卡表中的常见基础关键字（如圣盾、嘲讽、复生），只需修改实际变化；它们标为可编辑的参考默认值，不冒充独立核验结果。

## 本批版本与十个种族

按用户“全是当前最新录像”的声明，本批自动记为 **37.0.1**，核实日期2026-10-27。依据：[官方37.0.1热修](https://us.forums.blizzard.com/en/hearthstone/t/3701-hotfix-patch/166622)。版本记在 `tools/warband_collector/current_profile.json`，不需要逐局填写。以后换补丁时更新此全局配置，不自动改写旧版已标记记录。

十个按钮：**野兽、恶魔、龙、元素、机械、鱼人、海盗、野猪人、亡灵、畸变怪**。纳迦已轮换，参见[国服官方说明](https://hs.blizzard.cn/news/24294373/index.html)。中立、全部类型不是额外的大厅种族按钮。

选择的是“该大厅开放的种族”，不是当前阵容主玩什么。一般每局选5个；没看清可暂时跳过，不阻塞录入。以后库对手采样需要考虑同一大厅的可用种族，不要求对手与AI玩同一体系；合法生成的跨种族牌需要另行处理。

内置搜索仍使用引擎参考卡名数据；缺卡可“手动填新卡”，同版本录过的名称以后可直接搜。卡名参考表和录像补丁分开保存，不修改正在训练的Rust数据。

## 战斗信息的范围

录回合末成长结算后、开战效果前的阵容。无需逐条记录招募操作。若画面已经触发开战效果，可在折叠区勾“已触发过开战效果”，避免以后重复触发。

磁力附件、额外亡语、技能进度、召唤物/全局成长等只写会影响这场战斗的内容。已经施放法术留下的效果写最终效果，不必逐张补历史法术。手牌只保留参与战斗的部分，导出明确标记 `hand_scope=combat_only`，**不把省略的其他手牌解释为真正空手**。

接受人工近似输入，不以外部核验、截图或逐张“画面确认”作为采集准入。仍保留整数、数量等基本格式检查。系统不伪造“已核验”证据；这只是后台事实区分，不增加用户步骤。

## 保存与导出

正式文件仍在主项目 `runs/warband-collector`，历史修订与旧附件保留。右上“导出阵容”输出按整局分组的JSONL；“备份/恢复”里可导出完整ZIP或草稿JSON。改版不删除已有数据、既有图片或原先填过的信息，只从常用页面移除这些字段。

自动复制出来但还没填写的下一回合不进入阵容JSONL；备份会保留该草稿，以便继续录。填写后会自动进入导出，不要求额外审核。录到最后一回合，可直接点保存或新局，不必为了导出多建下一回合。

本工具输出为人工战团资料。首局前8回合已通过独立编译器转换为可加载、可战斗的原生代理；它不等于全部37.0.1卡牌均已适配，也尚未接入PPO对手库采样。原始采集文件保持独立。这一步不会再要求用户补来源/截图或重新核查每一局。

## 选卡筛选（2026-10-27改进）

默认按本局可用种族筛掉局外随从，保留中立、全部类型和至少一个类型可用的双种族牌。可选具体种族和1–7星；不输入文字也能浏览，按星级分组，再按种族、卡名排序。普通/金色合并显示，在战场勾“金”切换正确卡牌ID，保留你已填的当前攻血。特殊生成牌和局外种族在折叠筛选中按需打开。卡表仍是参考数据，不保证已覆盖全部最新卡牌。
